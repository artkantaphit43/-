Plant Piping TH

ระบบ – ท่อนี้ใช้กับงานอะไร (Service)
ชนิดท่อ (Pipe)
PVC, HDPE แข็ง / HDPE ม้วน (ดัดโค้ง), เหล็กดำ, สแตนเลส, GI, PP-R, ทองแดง
ความหนาผนังท่อ PVC เป็นค่าประมาณจากสูตรแรงดัน – ตรวจสอบกับแค็ตตาล็อกผู้ผลิตก่อนใช้งานจริง (PVC wall thickness is estimated)
การวาด (Drawing)
การแสดงผล / BOM
สีเองใช้กับท่อที่วาดใหม่ และท่อที่เลือกเมื่อกด "ปรับท่อที่เลือก"
ซัพพอร์ต (Pipe supports)
ท่อขนานกัน ระดับใต้ท่อต่างกัน ≤ 300 mm ใช้ซัพพอร์ตตัวเดียวกัน: แขวน → Trapeze, ขาตั้ง → H-frame, Sleeper → คานรองยาว, แขนผนัง/เสา → แขนยาว (≤ 1.2 m) · ท่อที่สูงกว่ามีแผ่นรอง · วาดท่อใหม่ข้างซัพพอร์ตเดิม → ขยายรับให้เอง
ยึดกับพื้น/ฝ้า/คาน/ผนังที่ตรวจพบในโมเดลอัตโนมัติ · ระยะห่างตาม MSS SP-69 / ค่าผู้ผลิตท่อพลาสติก
วาล์วและอุปกรณ์ (Valves & fittings)
เลือกอุปกรณ์ → ชี้ที่ท่อ: วาล์ว/มิเตอร์สแนปเข้าแนวท่อ, ข้องอ/ก๊อก/ฝาครอบสแนปที่ปลายท่อ, เกจติดบนท่อ · ขนาดปรับตามท่อที่ชี้ให้อัตโนมัติ · ← → หมุน 90°
ลำดับงานที่แนะนำ: เลือกระบบ → คำนวณขนาด → วาดท่อ (หรือแปลงเส้นจากแบบ CAD) → ใส่อุปกรณ์จากคลัง → กำหนดอัตราไหล → ตรวจไฮดรอลิก → ตรวจการชนกัน → ถอดวัสดุ
