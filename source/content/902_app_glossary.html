อภิธานศัพท์ไทย–อังกฤษ

คำศัพท์ที่ใช้ในคู่มือ
ภาษาไทยภาษาอังกฤษความหมายโดยย่อ
อัตราการไหลFlow rate (Q)ปริมาตรของเหลวต่อหน่วยเวลา
เฮดHead (H)พลังงานต่อหน่วยน้ำหนัก หน่วยเมตร
เฮดสถิตStatic headความต่างระดับผิวน้ำปลายทางกับต้นทาง
เฮดรวมTotal dynamic head (TDH)เฮดที่ปั๊มต้องสร้าง = เฮดสถิต + ความสูญเสีย
เฮดวาล์วปิดShut-off headเฮดของปั๊มที่อัตราไหลศูนย์
ความสูญเสียจากแรงเสียดทานFriction loss (major loss)พลังงานที่เสียไปตามความยาวท่อ
ความสูญเสียรองMinor lossพลังงานที่เสียไปที่อุปกรณ์และข้อต่อ
กราฟระบบSystem curveเฮดที่ระบบต้องการที่อัตราไหลต่าง ๆ
จุดทำงานOperating (duty) pointจุดตัดของกราฟปั๊มกับกราฟระบบ
จุดประสิทธิภาพสูงสุดBest efficiency point (BEP)อัตราไหลที่ปั๊มมีประสิทธิภาพสูงสุด
ช่วงแนะนำ / ช่วงที่ยอมรับได้POR / AORช่วงอัตราไหลที่แนะนำ/ยอมให้เดินได้ (ANSI/HI 9.6.3)
คาวิเทชันCavitationการเกิดและยุบตัวของฟองไอในปั๊ม
NPSH ที่ระบบมีให้ / ที่ปั๊มต้องการNPSHa / NPSH3 (NPSHr)เฮดสัมบูรณ์ด้านดูดเหนือความดันไอ
ความดันไอVapour pressureความดันที่ของเหลวเดือดที่อุณหภูมินั้น
การหมุนวนย้อนกลับRecirculationการไหลย้อนในใบพัดเมื่ออัตราไหลต่ำ
ความเร็วจำเพาะSpecific speed (nq, Ns)ตัวเลขบอกรูปทรงใบพัด
กฎความคล้ายAffinity lawsความสัมพันธ์ Q, H, P กับรอบและขนาดใบพัด
ตัวปรับความเร็วรอบVariable frequency drive (VFD)อุปกรณ์ปรับความถี่ไฟเพื่อปรับรอบมอเตอร์
การตัดใบพัดImpeller trimmingกลึงใบพัดให้เล็กลงเพื่อลดเฮด
ปั๊มดูดสองทาง / เรือนแยกDouble suction / split caseใบพัดรับน้ำสองด้าน เรือนสูบผ่าครึ่ง
ปั๊มเทอร์ไบน์แนวตั้งVertical turbine pump (VTP)ปั๊มแนวตั้งใบพัดจมน้ำ เพลายาว
ปั๊มจุ่มSubmersible pumpปั๊มและมอเตอร์กันน้ำจมอยู่ในของเหลว
ปั๊มสกรูเยื้องศูนย์Progressive cavity (PC) pumpปั๊ม PD โรเตอร์เกลียวในสเตเตอร์ยาง
ปั๊มแทนที่เชิงบวกPositive displacement (PD) pumpปั๊มที่ให้อัตราไหลคงที่ตามรอบ
แหวนกันสึกWear ringแหวนที่ควบคุมช่องว่างระหว่างใบพัดกับเรือนสูบ
ซีลกลMechanical sealอุปกรณ์กันรั่วที่เพลาด้วยหน้าสัมผัสเรียบ
บ่อเปียก / ห้องแห้งWet well / dry pitบ่อที่มีของเหลว / ห้องติดตั้งปั๊มแยก
การจมของปากดูดSubmergenceระยะจากผิวน้ำถึงปากดูด
ปริมาตรใช้งานActive (working) volumeปริมาตรระหว่างระดับหยุดกับระดับสั่งเดิน
ท่อส่งแรงดันForce main / rising mainท่อส่งจากปั๊มที่มีความดัน
ความสามารถสำรองFirm capacityความสามารถเมื่อปั๊มใหญ่สุดหนึ่งเครื่องไม่พร้อมใช้
แรงกระแทกของน้ำWater hammer / surgeคลื่นความดันจากการเปลี่ยนความเร็วอย่างกะทันหัน
ถังลมกันกระแทกSurge (air) vesselถังความดันลดแรงกระแทกของน้ำ
น้ำแยกตัวColumn separationการเกิดโพรงไอเมื่อความดันลดถึงความดันไอ
ประสิทธิภาพจากสายไฟถึงน้ำWire-to-water efficiencyผลคูณประสิทธิภาพปั๊ม มอเตอร์ และ VFD
ต้นทุนตลอดอายุLife cycle cost (LCC)มูลค่าปัจจุบันของค่าใช้จ่ายทั้งหมดตลอดอายุ
ตัวคูณชั่วโมงสูงสุดPeaking factorอัตราส่วนอัตราไหลสูงสุดต่อเฉลี่ย
น้ำซึมเข้า/น้ำฝนรั่วเข้าInfiltration / inflow (I/I)น้ำที่ไม่ใช่น้ำเสียที่เข้าสู่ท่อน้ำเสีย
ตะกอนย้อนกลับ / ส่วนเกินRAS / WASReturn / waste activated sludge
