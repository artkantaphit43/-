# Steel Supports TH (ซัพพอร์ตเหล็ก) – ปลั๊กอินแยก

ปลั๊กอิน SketchUp ตัวที่สอง (`dist/artk_steel_support-<version>.rbz`) สำหรับซัพพอร์ตท่อเหล็กรางน้ำ / ตัวซี
ตามแบบรายละเอียด 4 แบบ ขนาดเหล็กและอุปกรณ์ยึดเป็นขนาดจริง ใช้ได้เอง (ท่อทรงกระบอกทั่วไป) และใช้ร่วมกับ
**Plant Piping TH 1.16.1 ขึ้นไป** (อ่านขนาด/ฉนวน/น้ำหนักท่อจริง, วางตามแนวท่อ, Auto Supports ของ Plant Piping
ไม่วางซ้ำ, ลบที่แขวนเดี่ยวที่ตำแหน่งเดียวกัน, วาดท่อเพิ่มข้างซัพพอร์ต → ปรับตามให้เอง)

## แบบซัพพอร์ต

| แบบ | ตามแบบ | โครงสร้างที่ยึด | รายละเอียด |
|---|---|---|---|
| **WF โครงกล่องยึดผนัง/เสา** | C 4", พุก Expansion bolt 1/2" ×3 | ผนัง/เสาข้างท่อ (หาเองภายใน 3 m) | เสาหลังแนบผนัง, คานล่างรับท่อรัด U-bolt (ท่อสูงกว่ามีแผ่นรอง ≤ 300 มม.), คานบน + เสานอกปิดกล่อง · ท่อที่อยู่สูงกว่ากล่อง (ไอน้ำ/ท่อร้อน ≤ 1.2 m) วางบน shoe เหล็กฉาก 2 ตัวประกบบนคานบน (สูงพ้นฉนวน + 25 มม.) · ท่อห่างผนังได้ถึง 1.5 m |
| **WB ขาค้ำสามเหลี่ยมยึดผนัง** | C 3"/4", พุก 3/8" ×2 | ผนัง/เสาข้างท่อ | แขนบนรับท่อ, เสาแนบผนัง, ค้ำยัน 45° ใต้ท่อด้านนอก (ปลายตัดเฉียงชนหน้าเสา/ใต้แขน) |
| **TH แขวนใต้โครง Truss** | ก้าน 3/8"/1/2", C 3"/4" | ท่อกลม (chord) ของ truss เหนือท่อ ขวางแนวท่อ | ชิ้นรองรางน้ำ (toes ขึ้น – chord วางบนปีก) รัด U-bolt ข้าม chord, เหล็กเส้นเกลียวลงคานรับท่อ น็อต+แหวนบน/ล่างทุกจุด · วางที่กึ่งกลาง chord เอง (คลิกใกล้ truss ±600 มม.) · ใต้พื้นเรียบ → พุก drop-in |
| **TT วางบนโครง Truss** | C 3"/4" | ท่อกลมของ truss ใต้ท่อ ขนานแนวท่อ | เหล็กวางพาด chord (toes ลง), U-bolt คล้องใต้ chord ขันน็อตบนเหล็ก, ท่อรัด U-bolt ด้านบน · chord ต่ำกว่าเส้นอื่น ≤ 30 มม. มีแผ่นหนุน · ท่อต่ำกว่าระดับวางได้ → แจ้งให้ยกท่อ |

## ขนาดจริงที่ใช้

- **เหล็กรางน้ำ** (มอก. 1227 / JIS G 3192) H×B×t1×t2, r1/r2: C75×40×5×7 (3"), C100×50×5×7.5 (4"),
  C125×65×6×8 (5"), C150×75×6.5×10 (6") – คิดคุณสมบัติหน้าตัดจากตาราง JIS (ปีกเรียว)
- **เหล็กตัวซี** (มอก. 1228 / JIS G 3350) H×A×C×t: 75×45×15×2.3, 100×50×20×2.3, 100×50×20×3.2, 125×50×20×3.2,
  150×50×20×3.2 (มุมพับรัศมีใน = t)
- **เหล็กฉาก** L50×50×5, L65×65×6, L75×75×6, L100×100×7 (r1/r2 ตามตาราง)
- รูปตัดที่วาดคิดพื้นที่แล้วน้ำหนักตรงตารางภายใน 1 % (ทดสอบทุกขนาด) → ความยาว × กก./ม. ใน BOM เป็นน้ำหนักจริง
- **น็อต** hex ASME B18.2.2, **แหวน** SAE, **U-bolt** ขนาดเกลียวตามท่อ (½"–2" = 3/8", 2½"–6" = 1/2",
  8"–10" = 5/8") คร่อมผิวฉนวน, **เหล็กเส้นเกลียว** แรงที่ยอมให้ MSS SP-58 (3/8" 2.71 kN, 1/2" 5.03 kN …)
- **พุก Expansion** ฝังลึก/แรงที่ยอมให้แบบทั่วไปในคอนกรีต 210 ksc (FS 4) – ใช้เตือนเท่านั้น ให้ตรวจค่าผู้ผลิต

## การตรวจกำลังและการเลือกขนาดอัตโนมัติ

น้ำหนักท่อ = ท่อ + ของเหลว + ฉนวน (Plant Piping: จากแคตตาล็อกจริง, ท่อทั่วไป: เหล็ก Sch 40 เต็มน้ำ) × ระยะห่าง
ซัพพอร์ต (ตั้งเอง หรือระยะสูงสุดตามขนาด/วัสดุท่อ) · คานคิดเป็นคานสองจุดรองรับ + ส่วนยื่น รับแรงจุด:
หน่วยแรงดัด ≤ 0.6Fy (SS400 = 147 MPa, แกนอ่อนเพราะวางเหล็กหงาย/คว่ำ), แอ่น ≤ L/240 · ค้ำยัน: แรงอัด ≤ Fa (AISC ASD)
· พุก: แรงดึงจากโมเมนต์พลิก (หมุนรอบปลายล่างของเสา) + แรงเฉือน, T/Ta + V/Va ≤ 1 · ก้านแขวน: แรงปฏิกิริยา ≤ MSS SP-58
อัตโนมัติ = เหล็กเล็กที่สุดตั้งแต่ขนาดตามแบบ (WF เริ่ม 4", แบบอื่นเริ่ม 3") ที่ผ่าน, พุก/ก้านเล็กที่สุดที่รับแรงได้ ·
เลือกเองแล้วไม่ผ่าน → เส้นตัวอย่างสีแดง + ขึ้นในรายงาน

## วิธีใช้

- แถบเครื่องมือ **Steel Supports TH** / เมนู Extensions → Steel Supports TH
- เลือกแบบ (หรือกดปุ่มแบบนั้นบนแถบ) → ชี้ที่ท่อ → เส้นส้ม = แบบที่จะวาง (แดง = ไม่ผ่านการตรวจ/วางไม่ได้ ดูข้อความ) → คลิก ·
  **Tab** เปลี่ยนแบบ · ท่อข้างเคียง (ห่าง ≤ 600 มม.) รับไปด้วยในตัวเดียว
- **วางตามแนวท่อที่เลือก** (ท่อ Plant Piping): วางแบบที่เลือกตามระยะห่างสูงสุด เว้นช่วงที่มีซัพพอร์ตอยู่แล้ว
- **ปรับตามท่อ**: สร้างใหม่ตามท่อปัจจุบัน (เลขเดิม) – ทำเองอัตโนมัติเมื่อวาด/แก้ท่อด้วย Plant Piping
- **รายการวัสดุ + ตรวจกำลัง**: เหล็กแยกขนาด (ยาวรวม +5 % เผื่อตัด, กก.), แผ่นรอง, U-bolt, เหล็กเส้นเกลียว, พุก,
  น็อต+แหวน, ผลตรวจทุกตัว · บันทึก CSV (เปิดใน Excel ภาษาไทยได้)
- ซัพพอร์ตอยู่ใน Tag "ซัพพอร์ตเหล็ก (Steel supports)" ชื่อกลุ่ม `WF-01 …` ตามลำดับต่อแบบ

## ข้อมูลที่เก็บในโมเดล (ห้ามเปลี่ยนความหมาย – เพิ่ม key ได้อย่างเดียว)

กลุ่มละหนึ่งซัพพอร์ต, dictionary `ArtK_SteelSupport`:

| key | ความหมาย |
|---|---|
| `kind` | `support` |
| `format` | 1 |
| `detail` | `wf` / `wb` / `th` / `tt` |
| `number` | เช่น `WF-01` (ตัวนับใน model attribute `seq_<detail>`) |
| `section`, `anchor`, `rod` | หน้าตัดที่ใช้ (`C100` …), ขนาดพุก/ก้าน (`1/2` …) |
| `origin`, `xdir`, `ydir` | กรอบของซัพพอร์ต (world mm): x ตามแนวท่อ, y ขวาง (WF/WB: ออกจากผนัง), z ขึ้น |
| `hit_dir`, `ref` | ท่อที่คลิก (ทิศ, แหล่ง `pp`/`generic`, pid, ทรงกระบอก) – ใช้ปรับตามท่อ |
| `opts` | ค่าที่ใช้ตอนวาง |
| `pipes` | JSON `[{pid, label, y, z, od, ins, src, at}]` – `at` = จุดบนแกนท่อ (world) ที่ Plant Piping นับเป็นจุดรองรับ |
| `struct` | ผนัง (`wall`) / chord (`kind`, `z`, `r`) / chords |
| `bom`, `checks`, `notes`, `info` | รายการวัสดุ, ผลตรวจ, หมายเหตุ ของตัวนี้ |

## ใช้ร่วมกับ Plant Piping (API)

Plant Piping 1.16.1 มี `ArtK::PlantPipe::API` (LEVEL 1) ให้ปลั๊กอินอื่นเรียก: `pipe_at`, `pipes_across`, `info`,
`runs`, `support_points`, `drop_hangers`, `register_supports`, `on_runs_changed`, `ours?` (ดู `src/artk_plant_pipe/su/api.rb`).
Steel Supports ลงทะเบียน `register_supports` (Auto Supports ของ Plant Piping เว้นจุดที่ซัพพอร์ตเหล็กรับอยู่) และ
`on_runs_changed` (ปรับตามเมื่อวาดท่อ) · ปลั๊กอิน PipeBracket ใช้ `SupportBuilder.register_external` /
`drop_covered(model, point, pipes)` ซึ่งยังใช้ได้เหมือนเดิม
