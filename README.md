# สรุปหน้างานท่อ

หน้าเว็บบนมือถือสำหรับ PE คุมงานท่อในโรงงาน (น้ำเย็น · น้ำประปา · ไอน้ำ · ลมอัด)
ใช้กรอก 4 ช่อง แนบรูป แล้วกดปุ่มเดียวให้ได้ข้อความสรุปไว้ส่ง LINE

ไฟล์เดียวจบ: [`index.html`](index.html) ไม่ต้องลงแอป ไม่ต้องล็อกอิน ข้อมูลไม่ถูกส่งไปที่ไหน

---

## วิธีทำงาน (ฉบับตกลง)

### ทุกครั้งที่คุยงาน

| ช่วง | ทำอะไร | ในหน้าเว็บ |
|---|---|---|
| ระหว่างคุย | ถ่ายรูปจุดงานด้วย**แอปกล้องปกติ** และกรอก 4 ช่องด้วยการพูด (กดไมค์บนคีย์บอร์ด) ยังไม่ต้องกรอกให้ครบตอนนี้ | แตะเลือกระบบ → ใคร / ทำอะไร / เมื่อไร / ที่ไหน → เพิ่มรูป |
| ก่อนจบ | ไล่ดูรายการ "ก่อนจบ ถามครบยัง" แล้ว**ทวนกลับ**: อ่านข้อความสรุปให้อีกฝ่ายฟัง | กด **สร้างข้อความสรุป** → อ่านออกเสียง → ไม่ตรงกด **แก้ไข** |
| ทันที (ไม่เกิน 2 นาที) | ส่งสรุปเข้า LINE ของอีกฝ่าย | กด **① ส่งข้อความเข้า LINE** → เลือกแชท → กด **② ส่งรูป** |

### ก่อนเลิกงาน (10 นาที)

1. เลื่อนลงไปที่ **บันทึก** แล้วดูเรื่องที่ขึ้นป้าย **ยังไม่ส่ง** ถ้ามี ให้ส่งให้ครบ
2. กด **คัดลอกเป็นตาราง** แล้ววางต่อท้ายตารางใน Excel / Google Sheets
3. ไล่ดูคอลัมน์ "กำหนดวันที่" ว่าพรุ่งนี้มีงานไหนต้องตาม

ครั้งแรกให้กด **ตั้งค่าข้อความ → คัดลอกหัวตาราง** แล้ววางเป็นแถวแรกของตารางก่อน

### กติกา 4 ช่อง

| ช่อง | ต้องได้ | ใช้ไม่ได้ |
|---|---|---|
| **ใคร** | ชื่อคน 1 คน + สังกัด เช่น "พี่สมชาย (ผู้รับเหมา ABC)" | "ช่าง", "ทีมงาน", "เดี๋ยวให้น้องทำ" |
| **ทำอะไร** | กริยา + ของ + ขนาด, 1 บรรทัด = 1 งาน เช่น "เปลี่ยนบอลวาล์ว 2" ไลน์ CHWS" | "จัดการท่อ", "ดูให้หน่อย" |
| **เมื่อไร** | วัน + เวลา เช่น "พฤ. 1 ต.ค. ก่อนเที่ยง" | "เดี๋ยว", "เร็วๆ นี้", "ว่างๆ" |
| **ที่ไหน** | ตำแหน่งที่คนอื่นหาเจอ + รูป เช่น "อาคาร 2 แนวเสา C-4" | "ตรงนั้น", "ข้างๆ ปั๊ม" |

**ช่องไหนยังไม่ได้ข้อสรุป ให้ส่งไปเลย ไม่ต้องรอให้ครบ** ในข้อความช่องนั้นจะขึ้นว่า `❓ ยังไม่ได้ตกลง`
ทั้งสองฝ่ายจะเห็นตรงกันว่ายังมีเรื่องค้างต้องตามต่อ

### ก่อนจบ ถามครบยัง

หน้าเว็บจะมีรายการคำถามตามระบบที่เลือก (ติ๊กเมื่อถามแล้ว) เพื่อกันลืมรายละเอียดเล็กๆ:

- **ทุกงาน:** ต้องหยุดเครื่อง/หยุดไลน์ไหม แจ้งฝ่ายผลิตหรือยัง · มีงานเชื่อม/ตัดไหม (ใบอนุญาตงานร้อน) · ของและอุปกรณ์ใครเตรียม
- **น้ำเย็น:** ไลน์ Supply หรือ Return, ขนาดท่อ · ต้อง drain / ไล่อากาศไหม · หุ้มฉนวนคืนใครทำ
- **น้ำประปา:** ปิดน้ำโซนไหน กี่โมงถึงกี่โมง · ขนาดและวัสดุท่อ (PPR / PVC / GI) · เทสรั่ว
- **ไอน้ำ:** ความดันไลน์ (bar), ขนาดท่อ · ปิดวาล์ว + LOTO ใครล็อก รอท่อเย็นก่อนแกะ · หุ้มฉนวนคืน เช็กสตีมแทรป
- **ลมอัด:** ความดันใช้งาน (bar), ขนาดท่อ · ปิดวาล์วแยกโซน ระบายลมก่อนแกะ · เทสรั่วด้วยน้ำสบู่

แก้รายการนี้ได้ที่ตัวแปร `SYSTEMS` และ `ASK_COMMON` ใน `index.html`

```
📅 เมื่อไร: พฤ. 1 ต.ค. ก่อนเที่ยง
📍 ที่ไหน: ห้องบอยเลอร์ หน้า Header

📷 รูปประกอบ 2 รูป (ส่งตามในแชทนี้)

ถ้าไม่ตรงตามนี้ รบกวนแจ้งกลับครับ 🙏
```

## เปิดใช้บนมือถือ

1. บน GitHub เข้า repo นี้ → **Settings → Pages**
2. ที่ **Source** เลือก **Deploy from a branch** → เลือก branch ที่มี `index.html` และโฟลเดอร์ `/ (root)` → **Save**
3. รอประมาณ 1 นาที แล้วเปิด `https://artkantaphit43.github.io/-/` บนมือถือ
4. เพิ่มลงหน้าจอโฮม (iPhone: Safari → แชร์ → เพิ่มไปยังหน้าจอโฮม · Android: Chrome → ⋮ → เพิ่มลงในหน้าจอหลัก)

## ข้อควรรู้

- **บันทึกเก็บอยู่ในเบราว์เซอร์ของมือถือเครื่องนี้เท่านั้น** ถ้าล้างข้อมูลเบราว์เซอร์ บันทึกจะหาย จึงต้องย้ายเข้าตารางทุกเย็น (ระบบเก็บให้ย้อนหลังไม่เกิน 60 วัน)
- **รูปไม่ถูกเก็บในบันทึก** รูปจะอยู่ในแชท LINE และในคลังภาพ ถ่ายด้วยแอปกล้องปกติจะดีกว่า เพราะรูปที่ถ่ายผ่านหน้าเว็บบน iPhone จะไม่ถูกบันทึกลงคลังภาพ
- ปุ่ม **ส่งรูป** ใช้ได้บน Chrome (Android) และ Safari (iPhone) ถ้ามือถือไม่รองรับ ให้แนบรูปในแชท LINE เอง
- ระหว่างกรอก ถ้าจอดับหรือสลับแอป ข้อความที่กรอกค้างไว้จะยังอยู่ (ยกเว้นรูป)
- ตั้งชื่อผู้ส่งและประโยคท้ายข้อความได้ที่ **ตั้งค่าข้อความ** ด้านล่างสุดของหน้า
