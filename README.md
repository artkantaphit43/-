# ออกแบบ Weir V-notch 90° สำหรับวัดอัตราการไหล + บ่อปั๊มจุ่มด้านน้ำเข้าสำหรับ Water Recycle

ชุดนี้ออกแบบเวียร์สามเหลี่ยม 90° แบบ fully contracted สำหรับวัดอัตราการไหลในรางเปิด โดยวาง **บ่อปั๊มจุ่มไว้ที่ด้านน้ำเข้า (ก่อนเวียร์)** เพื่อสูบน้ำไป Water recycle และมี **ผนังกันน้ำกระฉอก (splash baffle)** กั้นระหว่างจุดที่น้ำเข้ากับปั๊ม

```
ท่อน้ำเข้า → [โซนน้ำเข้า | ผนังกันน้ำกระฉอก | โซนปั๊ม] → แผ่นกันคลื่นรูพรุน → รางนำน้ำ → V-notch 90° → บ่อน้ำออก → ท่อน้ำออก
                                                  │
                                             ปั๊มจุ่ม → Water recycle
```

| ไฟล์ | รายละเอียด |
|---|---|
| `weir_design.py` | โปรแกรมคำนวณและตรวจสอบแบบ ปรับ Qmax, Q recycle และขนาดต่าง ๆ ได้ |
| `make_drawings.py` | สร้างแบบ SVG ในโฟลเดอร์ `drawings/` |
| `rating_table.csv` | ตาราง h–Q (rating curve) ทุก 5 มม. |
| `drawings/*.svg` | รูปตัดตามยาว แปลน และรายละเอียดแผ่นเวียร์ |

> **สมมติฐานตั้งต้น**
> - น้ำเข้าสูงสุด **Qin = 10 L/s (36 m³/h)**
> - สูบไป Recycle **Qr = 5 L/s (18 m³/h)**
>
> ถ้าค่าจริงไม่ตรงกับนี้ ให้รันใหม่ด้วย `python3 weir_design.py --qmax <L/s> --q-recycle <L/s>`

### สิ่งที่เวียร์วัดได้เมื่อปั๊มอยู่ด้านน้ำเข้า

ปั๊มดึงน้ำออกไปก่อนถึงเวียร์ ดังนั้นเวียร์จะวัดเฉพาะ **น้ำที่ไหลออกจากระบบจริง (Qout = Qin − Qr)**
- ถ้าต้องการรู้ปริมาณน้ำเข้าทั้งหมด ให้ติด **flow meter บนท่อส่งของปั๊ม** แล้วคิด **Qin = Q<sub>weir</sub> + Q<sub>pump</sub>**
- เมื่อปั๊มหยุด (เสีย/ซ่อม/ระดับน้ำต่ำ) น้ำทั้งหมดจะผ่านเวียร์ ขนาดเวียร์จึงออกแบบให้รับ Qin สูงสุดได้เต็ม 10 L/s

## 1. หลักการและสมการ

ใช้สมการ **Kindsvater–Shen** ตามมาตรฐาน ISO 1438 / USBR Water Measurement Manual

$$Q = C_e \cdot \frac{8}{15}\sqrt{2g}\,\tan\frac{\theta}{2}\,(h + k_h)^{5/2}$$

สำหรับ θ = 90°: C<sub>e</sub> = 0.578, k<sub>h</sub> = 0.85 mm

$$\boxed{Q\;[\text{m}^3/\text{s}] \approx 1.365\,(h + 0.00085)^{2.5}}\qquad h \text{ หน่วยเป็น m วัดจากยอด V}$$

### เงื่อนไขของ fully contracted 90° V-notch

| เงื่อนไข | เกณฑ์ | แบบนี้ |
|---|---|---|
| ช่วงความสูงน้ำ h | 0.05 – 0.38 m | 0.05 – 0.139 m ✔ |
| h / P | ≤ 0.4 | 0.31 ✔ |
| h / B | ≤ 0.2 | 0.15 ✔ |
| ความสูงยอด V จากพื้น P | ≥ 0.45 m | 0.45 m ✔ |
| ความกว้างราง B | ≥ 0.90 m | 0.90 m ✔ |
| ความเร็วน้ำในรางนำน้ำ | < 0.15 m/s | 0.019 m/s ✔ |
| ระดับน้ำท้ายเวียร์ | ต่ำกว่ายอด V ≥ 60 mm (ไหลแบบ free fall) | พื้นบ่อน้ำออกอยู่ที่ −0.30 ส่วนท่อออกไหลอิสระ ✔ |

**ช่วงวัด:** 0.80 – 10 L/s (2.9 – 36 m³/h) ความคลาดเคลื่อนประมาณ ±1–2 % เมื่อติดตั้งได้ตามแบบ

## 3. ส่วนประกอบและขนาด (เรียงตามทิศทางการไหล)

### 3.1 บ่อน้ำเข้า / บ่อปั๊ม (ภายใน 1.40 × 1.20 m, พื้นอยู่ที่ระดับ −1.000)

บ่อนี้แบ่งเป็น 2 โซนด้วย **ผนังกันน้ำกระฉอก**

**(ก) โซนน้ำเข้า (ยาว 0.45 m)**
- ท่อน้ำเข้าเข้าบ่อที่ระดับท้องท่อ +0.65 แล้ว **ต่อข้องอลงเป็นท่อจุ่ม (dip pipe)** ให้ปลายท่ออยู่ที่ −0.50 ซึ่งต่ำกว่าระดับ STOP ของปั๊ม ปลายท่อจึงจมน้ำตลอดเวลา น้ำไม่ตกกระแทกผิวน้ำ ไม่กระฉอก และไม่พาอากาศลงบ่อ
- ปิดด้านบนด้วย **ฝา Checker plate** เพื่อกันน้ำกระเด็นออกนอกบ่อ และทำช่องเปิดไว้สำหรับตรวจ
- ถ้ามีขยะ ให้ติดตะแกรงหยาบ (bar screen) หรือตะกร้าดักขยะที่โซนนี้

**(ข) ผนังกันน้ำกระฉอก (Splash / Under-flow baffle)**

| รายการ | ค่า |
|---|---|
| วัสดุ | คสล. หนา 0.10 m หรือแผ่น SS304/PP หนา ≥ 6 mm ยึดโครงเหล็กกับผนัง |
| ขอบบน | +0.900 (เสมอสันกำแพง) น้ำกระฉอกจึงข้ามไปโซนปั๊มไม่ได้ |
| ขอบล่าง | −0.700 ให้น้ำ **ลอดใต้** ช่องสูง 0.30 m |
| ความเร็วลอดช่อง | 0.010 / (1.20 × 0.30) ≈ 0.03 m/s (ต่ำมาก) |

ผนังนี้ทำหน้าที่ 3 อย่าง: (1) กันคลื่นและน้ำกระฉอกจากน้ำเข้า (2) ให้ฟองอากาศลอยขึ้นในโซนน้ำเข้า ไม่ไหลไปถึงปั๊ม (3) ทำให้โซนปั๊มนิ่ง และส่งน้ำนิ่งต่อไปยังรางนำน้ำ

**(ค) โซนปั๊ม (ยาว 0.95 m)**

| รายการ | ค่า |
|---|---|
| อัตราสูบ | **Qr = 5 L/s (18 m³/h)** ส่วน TDH ให้คำนวณตามแนวท่อไปถัง Recycle |
| ปั๊ม | ปั๊มจุ่มติดตั้งบน **Guide rail + Auto-coupling** เพื่อยกขึ้นซ่อมได้ แนะนำให้มี 2 ตัว (Duty/Standby) |
| ท่อส่ง | Check valve + Gate valve + **Flow meter** (ใช้รวมยอดกับค่าจากเวียร์) |
| ตำแหน่งปั๊ม | กลางโซนปั๊ม ห่างผนังกันน้ำกระฉอก ≥ 0.3 m พื้นลาดเข้าหาปั๊ม 1:10 |

### 3.2 ระดับควบคุมปั๊ม

ในบ่อนี้ระดับน้ำ **ถูกคุมด้วยเวียร์** ขณะที่มีน้ำล้นเวียร์ ระดับน้ำจะอยู่ระหว่างยอด V (+0.45) ถึง +0.59

| ระดับ | ค่า (m) | หน้าที่ |
|---|---|---|
| สันกำแพง / ขอบบน baffle | +0.900 | |
| High-level alarm | +0.650 | ระดับน้ำสูงเกินปกติ แปลว่าเวียร์อุดตันหรือมีน้ำเข้ามากเกินแบบ |
| น้ำสูงสุด (ปั๊มหยุด, 10 L/s) | +0.589 | |
| ยอด V | +0.450 | |
| **ปั๊ม START** | **+0.350** | ต่ำกว่ายอด V 0.10 m จึงสูบต่อเนื่องเมื่อ Qin > Qr |
| **ปั๊ม STOP** | **−0.400** | กันปั๊มแห้ง ต้องสูงกว่าระดับต่ำสุดตามสเปกผู้ผลิต |
| ขอบล่าง baffle | −0.700 | STOP สูงกว่าขอบล่าง baffle อากาศจึงไม่ลอดไปถึงปั๊ม |
| พื้นบ่อปั๊ม | −1.000 | |

**การทำงาน**
- **Qin > Qr:** ปั๊มเดินตลอด ส่วนน้ำที่เหลือ (Qin − Qr) ล้นผ่านเวียร์ ซึ่งเป็นค่าที่วัดได้
- **Qin < Qr:** ระดับน้ำลดต่ำกว่ายอด V น้ำจึงหยุดไหลผ่านเวียร์ (ค่าที่อ่านได้ = 0 ซึ่งถูกต้อง) จากนั้นระดับจะลดจนถึง STOP ปั๊มหยุด แล้วระดับขึ้นไปถึง START ปั๊มเดินใหม่
- ปริมาตรทำงานระหว่าง START–STOP = 1.40 × 1.20 × 0.75 = **1.26 m³** (ต้องการ ≥ 0.45 m³ ตามเกณฑ์ไม่เกิน 10 starts/ชม.)
- กรณีที่ปั๊ม start ถี่ที่สุด (Qin = Qr/2) จะ start ประมาณ **3.6 ครั้ง/ชม.** ✔

### 3.3 ช่วงเปลี่ยนหน้าตัด + แผ่นกันคลื่นรูพรุน (ยาว 0.40 m)
- น้ำจากโซนปั๊มไหลขึ้นข้ามขั้นพื้น (±0.000) เข้ารางที่แคบลงจาก 1.20 m เหลือ 0.90 m
- **แผ่นกันคลื่นรูพรุน (perforated baffle)** ทำจาก SS304 หรือ PP มีรูเปิดราว 40–50 % ทำหน้าที่เป็น baffle ชั้นที่ 2 กระจายความเร็วให้เท่ากันทั้งหน้าตัด และกันคลื่นจากการเปิด–ปิดปั๊ม

### 3.4 รางนำน้ำ (Approach channel)
- กว้างภายใน **B = 0.90 m** ยาวตรง **2.00 m** (≥ 10·hmax) พื้นเรียบและได้ระดับ
- ผนัง คสล. หนา 0.20 m สันกำแพงอยู่ที่ +0.900

### 3.5 จุดวัดระดับน้ำ
- อยู่เหนือแผ่นเวียร์ **0.65 m** (ในช่วง 4–5·hmax)
- ใช้ **Stilling well** Ø100–150 mm ต่อเข้ารางด้วยท่อ Ø25 mm ที่ปากท่อเรียบเสมอผนัง และติดตั้ง **Ultrasonic level sensor** บนบ่อนี้
- ตั้ง **zero ของเซนเซอร์ = ระดับยอด V (+0.450)** โดยวัดจริงด้วยกล้องระดับหรือ point gauge และติด staff gauge ไว้ตรวจเทียบ

### 3.6 แผ่นเวียร์ V-notch 90°
| รายการ | ค่า |
|---|---|
| วัสดุ | SS304 (หรือ SS316 ถ้าน้ำกัดกร่อน) หนา 6 mm |
| มุมร่อง | 90° ± 0.1° โดยเส้นแบ่งครึ่งมุมต้องตั้งดิ่ง |
| ความลึกร่อง | 0.25 m (ปากกว้าง 0.50 m) รับได้ราว 24 L/s ก่อนน้ำล้นปากร่อง |
| ความสูงยอด V จากพื้นราง (P) | 0.45 m |
| ขอบร่อง | สันคม กว้าง 1–2 mm ด้านเหนือน้ำ ลบมุม 45° ด้านท้ายน้ำ |
| ขนาดแผ่น | กว้าง 1.10 m (ฝังร่องผนังข้างละ 0.10 m) สูง 0.80 m ยึดด้วย gasket EPDM และพุก SS |

ด้านเหนือน้ำของแผ่นต้องเรียบ ห้ามมีหัวน็อตหรือโครงยื่นใกล้ขอบร่อง

### 3.7 บ่อน้ำออก (ยาว 0.60 m, กว้าง 1.20 m, พื้นอยู่ที่ระดับ −0.300)
- บ่อนี้กว้างกว่าราง อากาศจึงเข้าใต้ม่านน้ำ (nappe) ได้
- ใช้ท่อน้ำออก Ø150 mm ท้องท่ออยู่ระดับพื้นบ่อ และต้อง **ไหลออกอิสระ** ห้ามมีอะไรทำให้น้ำท้ายเวียร์ยกตัวสูงถึง +0.39

## 4. ข้อควรระวัง

1. **ห้ามให้ปั๊มสูบเกิน Qin เป็นเวลานาน** ถ้า Qr ≥ Qin น้ำจะไม่ล้นเวียร์เลย และปั๊มจะเดิน–หยุดเป็นรอบ ควรเลือก Qr ให้ต่ำกว่าน้ำเข้าช่วงปกติ หรือใช้ VFD คุมระดับไว้ที่ +0.35
2. ถ้าต้องการให้เวียร์วัด **น้ำเข้าทั้งหมด** ให้ใช้ Qin = Q<sub>weir</sub> + Q<sub>flow meter ปั๊ม</sub> (กำหนดเป็นสูตรใน PLC)
3. ช่วงที่ปั๊มเพิ่ง start หรือ stop ระดับน้ำจะเปลี่ยนชั่วคราว ให้ตั้ง damping/ค่าเฉลี่ยของ level sensor ไว้ราว 10–30 วินาที
4. ตะกอนจะสะสมที่พื้นบ่อปั๊มและหน้าแผ่นเวียร์ ควรล้างเป็นประจำ ส่วนขอบร่อง V ควรทำความสะอาดคราบตะไคร่และไขมันทุกสัปดาห์
5. ถ้า Q ผ่านเวียร์ต่ำกว่า 0.8 L/s (h < 50 mm) จะวัดได้ไม่แม่น ในกรณีนี้ให้พิจารณาใช้ V-notch 60° หรือ 22.5° แทน
