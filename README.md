# ออกแบบ Weir V-notch 90° สำหรับวัดอัตราการไหล + บ่อปั๊มจุ่มสำหรับ Water Recycle

ชุดนี้มี 2 ส่วน คือแบบโครงสร้างเวียร์สามเหลี่ยม 90° แบบ fully contracted ใช้วัดอัตราการไหลในรางเปิด และบ่อปั๊มจุ่มที่ต่อจากท้ายเวียร์ ใช้สูบน้ำที่ผ่านการวัดแล้วกลับไปถัง Recycle

| ไฟล์ | รายละเอียด |
|---|---|
| `weir_design.py` | โปรแกรมคำนวณ/ตรวจสอบแบบ (ปรับ Qmax และขนาดได้) |
| `make_drawings.py` | สร้างแบบ SVG ในโฟลเดอร์ `drawings/` |
| `rating_table.csv` | ตาราง h–Q (rating curve) ทุก 5 มม. |
| `drawings/*.svg` | รูปตัดตามยาว, แปลน, รายละเอียดแผ่นเวียร์ |

> **สมมติฐานตั้งต้น:** อัตราการไหลสูงสุด **Qmax = 10 L/s (36 m³/h)** ถ้าค่าจริงไม่เท่านี้ ให้รันใหม่ด้วย `python3 weir_design.py --qmax <L/s>`
> แล้วปรับขนาดตามผลที่ได้

## 1. หลักการและสมการ

ใช้สมการ **Kindsvater–Shen** ตามมาตรฐาน ISO 1438 / USBR Water Measurement Manual

$$Q = C_e \cdot \frac{8}{15}\sqrt{2g}\,\tan\frac{\theta}{2}\,(h + k_h)^{5/2}$$

สำหรับ θ = 90°: C<sub>e</sub> = 0.578, k<sub>h</sub> = 0.85 mm

$$\boxed{Q\;[\text{m}^3/\text{s}] \approx 1.365\,(h + 0.00085)^{2.5}}\qquad h \text{ หน่วยเป็น m วัดจากยอด V}$$

(ค่านี้ใกล้กับสูตร Thomson แบบดั้งเดิม Q = 1.38 h<sup>2.5</sup> แต่แม่นยำกว่าที่ h ต่ำ)

### เงื่อนไขของ fully contracted 90° V-notch

| เงื่อนไข | เกณฑ์ | แบบนี้ |
|---|---|---|
| ช่วงความสูงน้ำ h | 0.05 – 0.38 m | 0.05 – 0.139 m ✔ |
| h / P | ≤ 0.4 | 0.31 ✔ |
| h / B | ≤ 0.2 | 0.15 ✔ |
| ความสูงยอด V จากพื้น P | ≥ 0.45 m | 0.45 m ✔ |
| ความกว้างราง B | ≥ 0.90 m | 0.90 m ✔ |
| ระดับน้ำท้ายเวียร์ | ต่ำกว่ายอด V ≥ 60 mm (ต้องไหลแบบ free fall) | ต่ำกว่า ≥ 200 mm ที่ระดับ START ✔ |

**ช่วงวัด:** 0.80 – 10 L/s (2.9 – 36 m³/h) โดยความคลาดเคลื่อนประมาณ ±1–2 % เมื่อติดตั้งได้ตามแบบ

## 3. ส่วนประกอบและขนาด (เรียงตามทิศทางการไหล)

### 3.1 บ่อพักน้ำเข้า + แผ่นกันคลื่น (ยาว 0.60 m)
- ท่อน้ำเข้าลงด้านล่างหรือชนผนัง **ห้ามพุ่งตรงเข้ารางนำน้ำ**
- แผ่นกันคลื่นรูพรุน (perforated baffle) ทำจาก SS304 หรือ PP มีพื้นที่รูเปิดประมาณ 40–50 % เพื่อกระจายความเร็วให้เท่ากันทั้งหน้าตัด

### 3.2 รางนำน้ำ (Approach channel)
- กว้างภายใน **B = 0.90 m** ยาวตรง **2.00 m** (≥ 10·hmax) พื้นเรียบและได้ระดับ
- ความเร็วน้ำในรางที่ Qmax ประมาณ 0.019 m/s ซึ่งต่ำพอ (ควรต่ำกว่า 0.15 m/s) จึงไม่ต้องปรับแก้ค่า approach velocity
- ผนัง คสล. หนา 0.20 m สันกำแพงอยู่ที่ระดับ +0.900 (freeboard 0.31 m จากระดับน้ำสูงสุด)

### 3.3 จุดวัดระดับน้ำ (Head measurement)
- อยู่เหนือแผ่นเวียร์ **0.65 m** (อยู่ในช่วง 4–5·hmax = 0.56–0.70 m)
- ใช้ **Stilling well** Ø100–150 mm ที่ต่อเข้ารางนำน้ำด้วยท่อ Ø25 mm ปากท่อเรียบเสมอผนัง และติดตั้ง **Ultrasonic level sensor** ไว้บนบ่อนี้
- ต้องตั้ง **ศูนย์ (zero) ของเซนเซอร์ = ระดับยอด V (+0.450)** โดยวัดจริงด้วยกล้องระดับหรือ point gauge ตอนน้ำนิ่งพอดียอด V
- ติดไม้วัดระดับ (staff gauge) ไว้ด้วยเพื่อใช้ตรวจเทียบ

### 3.4 แผ่นเวียร์ V-notch 90°
| รายการ | ค่า |
|---|---|
| วัสดุ | SS304 (หรือ SS316 ถ้าน้ำกัดกร่อน) หนา 6 mm |
| มุมร่อง | 90° ± 0.1° โดยเส้นแบ่งครึ่งมุมต้องตั้งดิ่ง |
| ความลึกร่อง | 0.25 m (ความกว้างปาก 0.50 m) ซึ่งรับได้สูงสุดราว 24 L/s ก่อนน้ำล้นปาก |
| ความสูงยอด V จากพื้นราง (P) | 0.45 m |
| ขอบร่อง | สันคม กว้าง 1–2 mm ด้านเหนือน้ำ ลบมุม 45° ด้านท้ายน้ำ |
| ขนาดแผ่น | กว้าง 1.10 m (ฝังร่องผนังข้างละ 0.10 m) สูง 0.80 m |
| การยึด | ใช้ร่องพร้อม gasket EPDM และพุก SS โดยหน้าแผ่นต้องตั้งฉากกับพื้นและแกนราง |

- ด้านเหนือน้ำของแผ่นต้อง **เรียบ ห้ามมีหัวน็อตหรือเหล็กเสริมยื่น** ภายในระยะ 2·hmax จากขอบร่อง
- น้ำที่ตกจากเวียร์ (nappe) ต้อง **มีอากาศเข้าใต้ม่านน้ำได้** ซึ่งแบบนี้ทำได้เพราะบ่อท้ายกว้างกว่าราง (1.20 > 0.90 m)

### 3.5 โซนน้ำตก + ผนังกั้นใต้น้ำ (ยาว 0.60 m)
- เป็นโซนรับน้ำที่ตกจากเวียร์ เพื่อให้ **ฟองอากาศลอยตัวขึ้นก่อนที่น้ำจะไหลไปถึงปั๊ม** (ฟองอากาศทำให้ปั๊มเกิด cavitation/air lock และสึกหรอเร็ว)
- ใช้ **ผนังกั้นแบบลอดใต้ (under-flow baffle)** หนา 0.12 m ให้น้ำลอดช่องใต้ผนังสูง 0.30 m (ช่วง −1.000 ถึง −0.700)

### 3.6 บ่อปั๊มจุ่ม
| รายการ | ค่า |
|---|---|
| ขนาดภายใน (รวมโซนน้ำตก) | 1.80 × 1.20 m พื้นอยู่ที่ระดับ −1.000 |
| อัตราสูบ | ≥ 1.1·Qmax = **11 L/s (≈ 40 m³/h)** ส่วน TDH ให้คำนวณตามแนวท่อไปถัง Recycle |
| ปั๊ม | ปั๊มจุ่มน้ำเสีย/น้ำสะอาดตามคุณภาพน้ำ ติดตั้งบน **Guide rail + Auto-coupling** เพื่อยกขึ้นซ่อมได้โดยไม่ต้องลงบ่อ แนะนำให้มี **2 ตัว (Duty/Standby) สลับกันทำงาน** |
| ท่อส่ง | Check valve + Gate valve ติดตั้งเหนือบ่อ และควรติด flow meter แบบ electromagnetic บนท่อส่งด้วยเพื่อใช้ตรวจเทียบกับเวียร์ |

**ระดับควบคุม (ลูกลอยหรือ level sensor ในบ่อปั๊ม):**

| ระดับ | ค่า (m) | หมายเหตุ |
|---|---|---|
| ท่อน้ำล้น (Overflow) | +0.390 | ต่ำกว่ายอด V 60 mm ทำให้น้ำท้าย **ไม่มีทางท่วมเวียร์** แม้ปั๊มเสีย |
| High-level alarm | +0.330 | แจ้งเตือนหรือสั่งปั๊มตัวที่ 2 ทำงาน |
| ปั๊ม START | +0.250 | |
| ปั๊ม STOP | −0.400 | ต้องสูงกว่าระดับต่ำสุดที่ผู้ผลิตกำหนด (ให้น้ำท่วมมอเตอร์) |
| พื้นบ่อ | −1.000 | ทำพื้นลาดเข้าหาปั๊ม 1:10 เพื่อไม่ให้ตะกอนค้าง |

**ตรวจสอบปริมาตรทำงาน:**
- ปริมาตรระหว่าง START–STOP = 1.80 × 1.20 × 0.65 = **1.40 m³**
- ปริมาตรที่ต้องการ V = Q<sub>p</sub>·T<sub>min</sub>/4 = 0.011 × 360 / 4 = 0.99 m³ (กำหนด start ไม่เกิน 10 ครั้ง/ชม.) ✔
- กรณีที่ปั๊ม start ถี่ที่สุด (น้ำเข้า = Q<sub>p</sub>/2) จะ start ประมาณ **7 ครั้ง/ชม.** ✔

## 4. ข้อควรระวังสำคัญ

1. **ห้ามให้ระดับน้ำในบ่อปั๊มสูงถึงยอด V** ถ้าน้ำท้ายท่วมเวียร์ (submerged) ค่าที่วัดได้จะผิด ทุกระดับในบ่อปั๊มจึงออกแบบให้อยู่ต่ำกว่า +0.39 และมีท่อน้ำล้นช่วยอีกชั้น
2. **ห้ามนำน้ำที่สูบออกมาปล่อยกลับเข้ารางนำน้ำ** ถ้า Recycle loop ต้องการวนกลับต้นระบบ ให้คิดอัตราไหลซ้ำนี้ในการคำนวณด้วย
3. ตะกอนที่สะสมหน้าแผ่นเวียร์จะทำให้ค่า P ลดลง ควรล้างรางเป็นประจำ หรือทำวาล์ว/ท่อระบายตะกอนที่พื้นราง
4. ขอบร่องที่บิ่น มีตะไคร่ หรือคราบไขมัน ทำให้ค่าเพี้ยนได้หลายเปอร์เซ็นต์ ควรตรวจและทำความสะอาดทุกสัปดาห์
5. ถ้าน้ำมีขยะหรือเศษวัสดุ ควรติดตะแกรงหยาบ (bar screen) ที่บ่อพักน้ำเข้า
6. ถ้ามีช่วงที่ Q < 0.8 L/s (h < 50 mm) น้ำจะเกาะแผ่น (clinging nappe) และวัดได้ไม่แม่น ในกรณีนี้ให้พิจารณาใช้ V-notch 60° หรือ 22.5° แทน

## 6. วิธีใช้โปรแกรม

```bash
python3 weir_design.py                       # แบบตั้งต้น Qmax 10 L/s
```
