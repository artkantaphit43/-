# คู่มือการเลือกปั๊มสำหรับระบบผลิตน้ำประปาและระบบสูบน้ำเสีย

สื่อการสอนสำหรับวิศวกร (ภาษาไทย, A4, 106 หน้า) → **[pump-selection-handbook.pdf](pump-selection-handbook.pdf)**

## เนื้อหา

- **ภาคที่ 1 พื้นฐาน** – ชนิดของปั๊ม, ชลศาสตร์และเฮดรวม (TDH), กราฟระบบ, กราฟปั๊ม/BEP/POR, กฎความคล้ายและ VFD, ปั๊มขนาน/อนุกรม, NPSH และคาวิเทชัน, บ่อสูบและการจมของปากดูด, มอเตอร์ พลังงาน และ LCC, แรงกระแทกของน้ำ
- **ภาคที่ 2 การเลือกตามประเภทงาน** – ปั๊มในระบบผลิตน้ำประปา, ปั๊มในระบบน้ำเสียและโรงบำบัด, วัสดุ ซีล แบริ่ง, ขั้นตอนการเลือกปั๊ม 12 ขั้นและแบบฟอร์มข้อกำหนด
- **ภาคที่ 3 ตัวอย่างการออกแบบ** – สถานีสูบส่งน้ำประปา (3+1 เครื่อง), สถานีสูบน้ำเสีย (2+1 เครื่อง), สถานีสูบน้ำดิบที่ระดับน้ำแปรผัน (VTP + VFD)
- **ภาคที่ 4 การใช้งานจริง** – การทดสอบ ISO 9906 และการติดตั้ง, ตารางวิเคราะห์ปัญหา, ข้อผิดพลาดที่พบบ่อยและเช็กลิสต์ตรวจแบบ, แบบฝึกหัดพร้อมเฉลย
- **ภาคผนวก** – สรุปสูตร, ตารางอ้างอิงด่วน, อภิธานศัพท์ไทย–อังกฤษ, มาตรฐานและเอกสารอ้างอิง

กราฟปั๊มในตัวอย่างเป็นกราฟสมมติเพื่อการเรียนรู้ ค่าแนะนำเป็นแนวปฏิบัติทั่วไป งานออกแบบจริงต้องใช้ข้อมูลผู้ผลิตและมาตรฐานที่อ้างอิงในสัญญา

## สร้าง PDF ใหม่จากต้นฉบับ

ต้นฉบับอยู่ใน `source/` เนื้อหาแต่ละบทเป็น HTML ใน `source/content/` ตัวเลขทุกตัวในตัวอย่างคำนวณใน `source/calc.py` และกราฟทุกรูปสร้างเป็น SVG ด้วย `source/figs_charts.py` / `source/figs_diagrams.py` จึงแก้ข้อมูลแล้วสร้างใหม่ได้โดยตัวเลขในข้อความ ตาราง และกราฟยังสอดคล้องกัน

```bash
pip install pymupdf          # ใช้อ่านเลขหน้าเพื่อทำสารบัญและ bookmark
npm install playwright       # หรือใช้ Playwright/Chromium ที่ติดตั้งไว้แล้ว
cd source
python3 build.py             # → ../pump-selection-handbook.pdf
python3 check_strays.py      # ตรวจรอยหมึกเกินขอบหน้า (ควรเหลือเฉพาะหน้าคั่นภาคสีเข้ม)
```
