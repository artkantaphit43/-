# ติดตั้ง Punch List Bot (Google Sheets) — ครั้งเดียวจบ ~15 นาที

หลังติดตั้งเสร็จ ใช้งานในไลน์อย่างเดียว ไม่ต้องเปิด Sheet หรือ Apps Script อีก

## ได้อะไร

```
Google Drive ของคุณ
├─ Punch List ภาพรวม            ← Sheet ที่ใส่โค้ด: ทุกโครงการ ค้าง/เสร็จกี่รายการ (ให้หัวหน้าดู)
└─ Punch List/
   ├─ คอนโด ABC/                ← สร้างเองอัตโนมัติเมื่อเชิญบอทเข้ากลุ่ม (ชื่อตามชื่อกลุ่มไลน์)
   │  ├─ Punch List - คอนโด ABC ← Sheet ของโครงการ: ทุกรายการ + รูป + ความคิดเห็นย้อนหลัง (ให้ลูกค้าดู)
   │  ├─ รูป/
   │  └─ รายงาน PDF/            ← PDF ทุกวันจันทร์ 07:00 (เก็บเป็นประวัติ)
   └─ บ้าน คุณ B/ ...
```

---

## ขั้นที่ 1: สร้างบอทใน LINE (~5 นาที)

1. เข้า https://developers.line.biz/console/ ล็อกอินด้วยบัญชีไลน์
2. **Create a new provider** → ตั้งชื่ออะไรก็ได้ (เช่นชื่อตัวเอง)
3. **Create a Messaging API channel** → กรอกชื่อบอท (เช่น "Punch List") → หมวดหมู่อะไรก็ได้ → Create
4. แท็บ **Messaging API**:
   - เลื่อนล่างสุด **Channel access token** → กด **Issue** → คัดลอกเก็บไว้ (ใช้ขั้นที่ 2)
   - **Allow bot to join group chats** → Edit → เปิด (Enabled)
   - **Auto-reply messages** → Edit → ปิด (Disabled)
   - **Greeting messages** → ปิด
5. สแกน QR code ในแท็บเดียวกันเพื่อเพิ่มบอทเป็นเพื่อน

## ขั้นที่ 2: วางโค้ดใน Google Sheet (~5 นาที)

> แนะนำใช้บัญชี Google ที่แยกไว้สำหรับงานนี้ ไม่ใช่บัญชีบริษัท

1. เปิด https://sheets.new → ตั้งชื่อไฟล์ว่า **Punch List ภาพรวม**
2. เมนู **ส่วนขยาย (Extensions) → Apps Script**
3. ลบโค้ดเดิมที่มีอยู่ทั้งหมด → วางโค้ดจากไฟล์ [`Code.gs`](Code.gs) ทั้งไฟล์
4. บรรทัดบน ๆ แก้ `'ใส่ Channel access token ตรงนี้'` เป็น token จากขั้นที่ 1 (เก็บเครื่องหมาย `'` ไว้)
5. กด 💾 บันทึก

## ขั้นที่ 3: Deploy (~3 นาที)

1. มุมขวาบน **Deploy → New deployment**
2. กดรูปเฟือง ⚙ ข้าง "Select type" → **Web app**
3. ตั้งค่า:
   - Execute as: **Me**
   - Who has access: **Anyone**
4. กด **Deploy** → **Authorize access** → เลือกบัญชี Google
   - ถ้าขึ้น "Google hasn't verified this app" → กด **Advanced** → **Go to ... (unsafe)** → **Allow**
     (ปกติสำหรับโค้ดที่เขียนใช้เอง Google แค่ยังไม่ได้ตรวจ)
5. คัดลอก **Web app URL** แล้ว**เปิดในเบราว์เซอร์** → จะเจอหน้าที่มี **Webhook URL** ให้คัดลอก

## ขั้นที่ 4: ต่อ LINE กับ Google (~2 นาที)

1. กลับไป LINE Developers Console → แท็บ **Messaging API**
2. **Webhook URL** → Edit → วาง URL จากขั้นที่ 3 → Update
3. เปิด **Use webhook**
   - ถ้ากด Verify แล้วขึ้น error `302` ไม่ต้องสนใจ เป็นลักษณะปกติของ Google Apps Script ใช้งานได้
4. เชิญบอทเข้ากลุ่มไลน์หน้างาน → บอทจะส่งวิธีใช้ + ลิงก์ Sheet ของโครงการมาให้เอง ✅

## ให้หัวหน้า / ลูกค้าดูผ่าน OneDrive

บอทไม่ต่อกับ OneDrive บริษัท แต่คุณวาง "ทางเข้า" ไว้ใน OneDrive ได้เอง ทำครั้งเดียว:

| ใคร | ให้ลิงก์อะไร | เห็นอะไร |
|---|---|---|
| หัวหน้า | **Punch List ภาพรวม** (แชร์ไฟล์นี้ให้อีเมลหัวหน้า หรือ "ทุกคนที่มีลิงก์ – ผู้มีสิทธิ์อ่าน") | ทุกโครงการ ค้าง/เสร็จกี่รายการ อัปเดตทุกครั้งที่มีคนพิมพ์ในไลน์ กดเข้าไปดูแต่ละโครงการได้ |
| ลูกค้า | พิมพ์ `ลิงก์` ในกลุ่มไลน์ของโครงการนั้น → ได้ลิงก์ Sheet + โฟลเดอร์ PDF | เฉพาะโครงการของตัวเอง ทุกรายการ ความคิดเห็นย้อนหลัง และ PDF รายสัปดาห์ |

วิธีวางใน OneDrive: สร้างไฟล์ Word หรือ Excel ในโฟลเดอร์ที่แชร์กัน (เช่น "Punch List - ลิงก์") แล้ววางลิงก์ด้านบนไว้ หัวหน้าเปิด OneDrive ตามปกติ → กดลิงก์ → เห็นข้อมูลล่าสุดเสมอ ไม่ต้องมีบัญชี Google

ถ้าต้องการไฟล์เก็บใน OneDrive จริง ๆ: เปิดโฟลเดอร์ **รายงาน PDF** → ดาวน์โหลดไฟล์ PDF → อัปโหลดเข้า OneDrive

## ตั้งค่าเพิ่มเติม (บนสุดของ Code.gs)

| ตัวแปร | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `WEEKLY_REPORT` | `true` | วันจันทร์ 07:00 ทำ PDF + ส่งสรุปเข้ากลุ่ม |
| `SHARE_WITH_LINK` | `true` | คนที่มีลิงก์เปิดดู Sheet/รูป/PDF ได้ (ถ้าปิด รูปย่อในตารางจะไม่ขึ้น และต้องแชร์ให้ทีละคนเอง) |

**โควตาข้อความ LINE:** การตอบกลับ (reply) ฟรีไม่จำกัด ส่วนสรุปรายสัปดาห์เป็นการส่งเอง (push) นับตามจำนวนคนในกลุ่ม เช่น กลุ่ม 10 คน = 10 ข้อความ/สัปดาห์ แพ็กเกจฟรีของ LINE OA มีโควตาต่อเดือนจำกัด ถ้าโครงการเยอะให้ตั้ง `WEEKLY_REPORT = false` แล้วพิมพ์ `รายงาน` เองเมื่อต้องการ

## อัปเดตโค้ดภายหลัง

วางโค้ดใหม่ทับ → บันทึก → **Deploy → Manage deployments** → ✏️ แก้ไข → Version: **New version** → Deploy
(URL เดิม ไม่ต้องแก้ใน LINE)

## แก้ปัญหา

- **บอทไม่ตอบ**: เช็กว่าเปิด Use webhook แล้ว, ปิด Auto-reply แล้ว, token ถูก, และ Deploy แบบ Who has access = **Anyone**
- **ดู error**: Apps Script → เมนูซ้าย **Executions (การดำเนินการ)**
- **รูปย่อในตารางไม่ขึ้น**: รอสักครู่แล้วรีเฟรช (Google ทำรูปย่อหลังอัปโหลด)
- **แก้ข้อมูลใน Sheet ตรง ๆ ได้ไหม**: ได้ เช่น แก้คำผิด แต่อย่าลบ/ย้ายคอลัมน์ และอย่าแก้เลขที่ในคอลัมน์ #
