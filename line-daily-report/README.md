# LINE Daily Report Bot

ส่งข้อมูลงานและรูปผ่าน LINE แล้วได้ **รายงานประจำวันเป็น PDF** กลับมาในแชต
ใช้แค่มือถือ ไม่ต้องใช้โน้ตบุ๊ก ไม่ต้องมีบัญชี AI และ**ฟรี** (ใช้ LINE OA + Google Apps Script)

```
พนักงาน (LINE) ──► LINE OA บอท ──► Google Apps Script
                                      ├─ เก็บรูปลง Google Drive
                                      ├─ คัดลอกฟอร์ม FM_Daily Report (Google Sheets) เติมข้อมูล + PDF
                                      └─ บันทึกลง Google Sheets
              ◄── ลิงก์ PDF ส่งกลับในแชต ◄──┘
```

## วิธีใช้งาน (สำหรับพนักงาน)

1. พิมพ์ **`เริ่ม`** แล้วบอทจะถามทีละข้อพร้อมปุ่มให้กด
   ผู้เขียนรายงาน → โครงการ → เวลาเริ่ม → เวลาเลิก (มีปุ่มทุกครึ่งชั่วโมง พิมพ์เวลาอื่นได้) → คนงาน → อากาศ → (ช่วงฝนตก) → อุณหภูมิ → รถ/เครื่องจักร → ผลกระทบ → อุบัติเหตุ
2. พิมพ์งานทีละข้อ เช่น `1. ขุดดินวางท่อ 60%` แล้วกด **📷 ถ่ายรูป** หรือ **🖼️ เลือกรูป** เพื่อส่งรูปของงานนั้น บอทจะบอกเลขข้อถัดไปให้
   - งานของอีกโครงการ: กด **➕ งานโครงการอื่น** แล้วพิมพ์รหัส เช่น `69014`
   - งานหมดแล้ว: กด **🏁 จบงานวันนี้**
3. บอทถามว่ามีแผนพรุ่งนี้ไหม ถ้ามีให้กด **🗓️ กรอกแผนพรุ่งนี้** แล้วตอบคนงาน รถ และพิมพ์งานพรุ่งนี้
4. กด **📋 ดูสรุป** เพื่อดูการ์ดสรุป ถ้าต้องแก้ข้อไหนให้กด **✏️ แก้ไข**
5. กด **✅ ส่งรายงาน** บอทจะตอบกลับเป็นลิงก์ PDF

ถ้าบอทถามตัวเลข (คนงาน อุณหภูมิ จำนวนรถ) จะพิมพ์ตัวเลขตอบเลยก็ได้ ส่วนการพิมพ์แบบ `หัวข้อ: ค่า` ยังใช้ได้เหมือนเดิม เช่น `คน: 15` หรือ `เลิกงาน: 3 ทุ่ม`

| คำสั่ง | ทำอะไร |
|---|---|
| `เริ่ม` | เริ่มหรือทำรายงานต่อ |
| `สถานะ` | ดูการ์ดสรุป |
| `ส่ง` | ออกรายงาน PDF |
| `ยกเลิก` | ล้างข้อมูลแล้วเริ่มใหม่ |
| `ชื่อ` | เปลี่ยนผู้เขียนรายงาน |
| `โครงการ` | ดูฐานข้อมูลโครงการ + ลิงก์ตารางสำหรับแก้ไข |
| `เพิ่มโครงการ` | เพิ่ม/แก้ข้อมูลโครงการ (บอทถามทีละข้อ) |
| `ลบโครงการ: PJ xxx` | ลบโครงการออกจากฐานข้อมูล |
| `ลายเซ็น` | ตั้งรูปลายเซ็น (ทำครั้งเดียว) |

> 💡 ตั้ง **Rich menu** (เมนูปุ่มใต้แชต) ได้ใน LINE Official Account Manager โดยให้ปุ่มส่งข้อความ `เริ่ม`, `สถานะ`, `ส่ง`

## ฐานข้อมูลโครงการ

รหัส PJ หนึ่งรหัสผูกกับชื่อโครงการ สถานที่ และลักษณะงานเสมอ ข้อมูลเก็บในแท็บ **ฐานข้อมูลโครงการ** ของชีตบันทึก (`LINE Daily Report - บันทึก`)

- พิมพ์ PJ ที่**มีในฐานข้อมูล** แล้วระบบเติมส่วนหัวรายงานให้อัตโนมัติ
- พิมพ์ PJ ที่**ยังไม่มี** บอทจะถามชื่อ สถานที่ และลักษณะงานทีละข้อ**ครั้งเดียว** แล้วบันทึกลงตาราง
- แก้ไขข้อมูลได้ทั้งในตารางโดยตรง หรือพิมพ์ `เพิ่มโครงการ` ในไลน์
- ส่วนหัวรายงานใช้โครงการหลัก (ที่เลือกตอนเริ่ม) ส่วนโครงการอื่นที่ทำในวันเดียวกันจะแสดงในสรุปผลการปฏิบัติงานและกรอบรูป

## ติดตั้ง (ทำครั้งเดียว ประมาณ 20 นาที)

### 1. สร้างบอท LINE
1. เข้า <https://developers.line.biz/console/> แล้วล็อกอินด้วยบัญชี LINE
2. สร้าง Provider แล้วสร้าง channel แบบ **Messaging API**
   (ถ้าระบบให้สร้าง LINE Official Account ก่อน ก็ทำตามขั้นตอนได้เลย)
3. ในแท็บ **Messaging API** ให้ทำดังนี้
   - กด **Issue** ที่ *Channel access token (long-lived)* แล้วคัดลอกเก็บไว้
   - **Allow bot to join group chats**: เปิด (ถ้าจะใช้ในกลุ่ม)
   - **Auto-reply messages** และ **Greeting messages**: ปิด

### 2. สร้าง Google Apps Script
1. เข้า <https://script.google.com> แล้วกด **New project**
2. ลบโค้ดเดิม แล้ววางโค้ดจาก `Code.gs`
3. ⚙️ **Project Settings**
   - ติ๊ก *Show "appsscript.json" manifest file* แล้ววางเนื้อหาจาก `appsscript.json` ทับ
   - ที่ **Script Properties** กด Add แล้วใส่
     `LINE_CHANNEL_ACCESS_TOKEN` = token จากขั้นที่ 1
4. กลับไปหน้า Editor เลือกฟังก์ชัน `setup` แล้วกด **Run** จากนั้นกดอนุญาตสิทธิ์
   ระบบจะสร้างโฟลเดอร์ `LINE Daily Report` และชีตบันทึกใน Google Drive ให้
5. (แนะนำ) เลือกฟังก์ชัน `testReport` แล้วกด **Run** เพื่อสร้างรายงานตัวอย่าง (มีรูปตัวอย่างให้ดูการจัดวาง)
   จากนั้นดูลิงก์ PDF ใน Execution log ว่าหน้าตาถูกต้องหรือไม่

### 3. เปิดใช้เป็น Webhook
1. กด **Deploy → New deployment → Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
2. คัดลอก **Web app URL**
3. กลับไปที่ LINE Developers ในแท็บ Messaging API
   - **Webhook URL**: วาง URL ที่คัดลอกมา
   - **Use webhook**: เปิด
4. สแกน QR ของบอทเพื่อแอดเพื่อน หรือเชิญบอทเข้ากลุ่มงาน แล้วพิมพ์ `ฟอร์ม` เพื่อทดสอบ

> ปุ่ม **Verify** ใน LINE อาจขึ้น error เพราะ Apps Script ตอบกลับด้วยการ redirect
> แต่ระบบยังทำงานปกติ ให้ทดสอบด้วยการส่งข้อความจริงแทน

> **แก้โค้ดภายหลัง** ให้ไปที่ Deploy → Manage deployments → ✏️ → Version: *New version*
> วิธีนี้ URL จะไม่เปลี่ยน ไม่ต้องไปแก้ใน LINE ใหม่

## ฟอร์มรายงาน

รายงานสร้างจาก**ฟอร์ม Excel จริงของบริษัท** (FM_Daily Report_R02) ที่ฝังไว้ในโค้ด
ตอนรัน `setup` ครั้งแรก ระบบจะแปลงฟอร์มนี้เป็น Google Sheets ชื่อ *แม่แบบ FM_Daily Report (ห้ามลบ)* ไว้ในโฟลเดอร์ `LINE Daily Report`
ทุกรายงานจะคัดลอกแม่แบบนี้ เติมข้อมูลลงช่องเดิม วางรูป แล้วแปลงเป็น PDF หน้าเดียว

- **กรอบภาพถ่ายขนาดคงที่** รูปจะถูกย่อหรือขยายให้พอดีกรอบเอง แยกตาม PJ และมีเลขวงกลมตามลำดับงาน
- สรุปงานมี 10 บรรทัด และแผนพรุ่งนี้มี 5 บรรทัด ถ้าเกิน ระบบจะยืมแถวจากกรอบรูป ทำให้รายงานยังเป็น 1 หน้า
- Google ไม่มีฟอนต์ Angsana New จึงใช้ **Sarabun** แทน ส่วน checkbox ใช้สัญลักษณ์ ☐ / ☑
- อยากแก้หน้าตาฟอร์ม (เช่น ข้อความหัวตาราง) แก้ในไฟล์แม่แบบบน Google Sheets ได้เลย แต่**อย่าเพิ่มหรือลบแถว/คอลัมน์** เพราะโค้ดอ้างอิงตำแหน่งช่องไว้ (ดู `TPL` ใน `Code.gs`)
- ถ้าลบแม่แบบไป ระบบจะสร้างใหม่ให้เอง หรือรัน `rebuildTemplate` เพื่อสร้างใหม่ทันที

สร้างแม่แบบใหม่จากไฟล์ Excel (สำหรับนักพัฒนา):
```
python3 tools/build_template.py <FM_Daily Report.xlsx> tools/template.xlsx
python3 tools/embed_assets.py tools/template.xlsx Code.gs
```

## ปรับให้ตรงกับบริษัท

แก้ `CONFIG` ที่ต้นไฟล์ `Code.gs`

- `REPORTERS`: รายชื่อผู้เขียนรายงาน (แสดงเป็นปุ่มได้สูงสุด 13 ชื่อ)
- `PROJECTS`: โครงการตั้งต้น (ปกติให้เพิ่มจากในไลน์แทน)
- `MACHINES`: คำที่ใช้พิมพ์เครื่องจักรแต่ละชนิด
- `PHOTO_MAX_HEIGHT`: ความสูงรูปสูงสุดในกรอบ (วันที่มีรูปน้อย)

## จำกัดคนใช้งาน (แนะนำ)

ใส่ Script Property `ALLOWED_SOURCE_IDS` เป็น groupId หรือ userId ที่อนุญาต (คั่นด้วย `,`)
บอทจะตอบเฉพาะกลุ่มหรือคนในรายการนี้ ดู ID ได้จาก Executions log ของ Apps Script

## ข้อควรรู้

- ข้อมูลทั้งหมด (รูป รายงาน ชีต) อยู่ใน Google Drive ของคนที่ติดตั้ง
- ลิงก์ PDF ตั้งค่าเป็น "ทุกคนที่มีลิงก์ดูได้" ถ้าบัญชี Google ของบริษัทปิดการแชร์แบบนี้ไว้ จะเปิดได้เฉพาะคนในบริษัท
- การตอบกลับ (reply) ของ LINE ฟรี แต่ถ้าสร้างรายงานนานจน reply หมดเวลา ระบบจะส่งแบบ push แทน ซึ่งนับรวมในโควตาข้อความฟรีรายเดือนของ LINE OA
- Apps Script อ่าน header ของ webhook ไม่ได้ จึงตรวจลายเซ็นของ LINE ไม่ได้ แนะนำให้ตั้ง `ALLOWED_SOURCE_IDS`
