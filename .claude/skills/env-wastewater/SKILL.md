# น้ำเสีย (Wastewater)

ทำตาม "รูปแบบรายงานการคำนวณ" ใน `CLAUDE.md` และใช้ Python คำนวณตัวเลขจริง ห้ามคิดในหัว

## 1. BOD
- BOD5 (ไม่เติมเชื้อ): `BOD = (D1 − D2) / P`
  - D1, D2 = DO วันแรก / วันที่ 5 (mg/L), P = ปริมาตรตัวอย่าง / ปริมาตรขวด (ปกติ 300 mL)
- BOD5 (เติมเชื้อ): `BOD = [(D1 − D2) − (B1 − B2)·f] / P`
  - B1, B2 = DO ของ seed control, f = สัดส่วน seed ในตัวอย่าง / seed ใน control
- BOD ตามเวลา: `BOD_t = L0 (1 − e^(−k·t))`, k20 ≈ 0.23 d⁻¹ (ฐาน e)
- ปรับ k ตามอุณหภูมิ: `k_T = k20 · θ^(T−20)`, θ ≈ 1.047
- BOD/COD > 0.5 → บำบัดทางชีวภาพได้ดี, < 0.3 → ย่อยยาก

## 2. ปริมาณน้ำเสียและภาระ
- น้ำเสีย ≈ 80% ของน้ำใช้ (ไทยในเมือง ~150–250 L/คน/วัน)
- `Q = ประชากร × อัตราน้ำเสียต่อคน`
- ภาระ BOD (kg/d) = `Q (m³/d) × BOD (mg/L) / 1000`
- อัตราไหลสูงสุด = Q เฉลี่ย × Peak factor (ปกติ 2–4 ชุมชนเล็กยิ่งสูง)

## 3. ระบบเอเอส (Activated Sludge)
- HRT: `θ = V / Q`
- F/M: `F/M = Q·S0 / (V·X)` (X = MLVSS)
- SRT: `θc = V·X / (Qw·Xw + Qe·Xe)`
- ค่าทั่วไป (conventional): F/M 0.2–0.4 d⁻¹, SRT 3–15 d, MLSS 1,500–3,000 mg/L, HRT 4–8 h
- Extended aeration: F/M 0.05–0.15, SRT 20–30 d, HRT 18–36 h
- อัตราผลิตสลัดจ์: `Px = Yobs·Q·(S0 − S)`, `Yobs = Y / (1 + kd·θc)` (Y ≈ 0.6, kd ≈ 0.06 d⁻¹)
- ออกซิเจน (อย่างง่าย): `O2 = Q(S0 − S)/f − 1.42·Px` (f = BOD5/BODu ≈ 0.68)

## 4. ถังตกตะกอน
- อัตราน้ำล้น: `SOR = Q / A`
- เวลากักเก็บ: `t = V / Q`, อัตราน้ำล้นเวียร์ = `Q / ความยาวเวียร์`
- ถังตกตะกอนขั้นต้น: SOR 30–50 m³/m²·d, t 1.5–2.5 h, weir 125–500 m³/m·d
- ถังตกตะกอนขั้นที่สอง: SOR 16–28 m³/m²·d, solids loading 4–6 kg/m²·h

## 5. บ่อปรับเสถียร (Stabilization Ponds)
- บ่อแอนแอโรบิก: ภาระ BOD 100–400 g/m³·d, HRT 1–5 d
- บ่อแฟคัลเททีฟ (สูตร Mara): `λs = 350·(1.107 − 0.002T)^(T−25)` kg BOD/ha·d
  - พื้นที่ `A (m²) = 10 · Li · Q / λs` (Li = BOD เข้า mg/L, Q m³/d)
- ผสมสมบูรณ์ 1 บ่อ: `Ce = C0 / (1 + k·t)`; n บ่อต่อกัน: `Ce = C0 / (1 + k·t)^n`

## 6. มาตรฐานน้ำทิ้งไทย (ค่าสูงสุด, ตรวจฉบับล่าสุดที่ pcd.go.th ก่อนใช้จริง)
- **อาคาร (2548)** BOD / SS (mg/L): ก 20/30, ข 30/40, ค 40/50, ง 50/50, จ 200/60, pH 5–9
- **โรงงานอุตสาหกรรม (2560)**: pH 5.5–9.0, BOD ≤ 20, COD ≤ 120, SS ≤ 50, TDS ≤ 3,000, น้ำมันและไขมัน ≤ 5, TKN ≤ 100 mg/L, อุณหภูมิ ≤ 40 °C
  (บางประเภทโรงงานอนุญาตให้สูงกว่านี้ได้ตามที่ประกาศกำหนด)
