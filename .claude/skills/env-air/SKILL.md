# มลพิษอากาศ (Air Pollution)

ทำตาม "รูปแบบรายงานการคำนวณ" ใน `CLAUDE.md` และใช้ Python คำนวณตัวเลขจริง

## 1. แปลงหน่วย
- `mg/m³ = ppm × MW / 24.45` (25 °C, 1 atm); ที่ 0 °C ใช้ 22.41
- ปรับเงื่อนไข: `C_std = C_actual × (P_std/P) × (T/T_std)` (T เป็น K)
- ปรับออกซิเจนอ้างอิง: `C_ref = C_meas × (20.9 − O2_ref) / (20.9 − O2_meas)`

## 2. อัตราการปล่อยมลพิษ
- `E = A × EF × (1 − ER/100)` (A = กิจกรรม, EF = emission factor, ER = ประสิทธิภาพการบำบัด %)
- จากปล่อง: `E (g/s) = C (g/m³) × Q (m³/s)`

## 3. เสถียรภาพบรรยากาศ (Pasquill A–F)
| ลม 10 m (m/s) | แดดแรง | แดดปานกลาง | แดดอ่อน | กลางคืน เมฆ ≥ 4/8 | กลางคืน เมฆ ≤ 3/8 |
|---|---|---|---|---|---|
| < 2 | A | A–B | B | F | F |
| 2–3 | A–B | B | C | E | F |
| 3–5 | B | B–C | C | D | E |
| 5–6 | C | C–D | D | D | D |
| > 6 | C | D | D | D | D |

ท้องฟ้าปิดทึบ (กลางวันหรือกลางคืน) ใช้ D

## 4. ความเร็วลมที่ความสูงปล่อง
- `u = u10 · (z/10)^p`, ชนบท p: A 0.07, B 0.07, C 0.10, D 0.15, E 0.35, F 0.55

## 5. การยกตัวของควัน (Plume Rise)
- สูตร Holland: `Δh = (vs·d/u) · [1.5 + 2.68×10⁻³ · P · ((Ts − Ta)/Ts) · d]` (P เป็น mb)
- สูตร Briggs (A–D): `Fb = g·vs·d²·(Ts − Ta)/(4Ts)`
  - Fb < 55: `Δh = 21.425·Fb^0.75 / u`
  - Fb ≥ 55: `Δh = 38.71·Fb^0.6 / u`
- ความสูงประสิทธิผล: `H = hs + Δh`

## 6. การกระจายแบบเกาส์เซียน
- `C(x,y,z) = Q/(2π·u·σy·σz) · exp(−y²/2σy²) · [exp(−(z−H)²/2σz²) + exp(−(z+H)²/2σz²)]`
- ที่พื้นแนวกลาง (y = 0, z = 0): `C = Q/(π·u·σy·σz) · exp(−H²/2σz²)`
- σ ของ Briggs (ชนบท, x เป็น m):
  - A: σy = 0.22x(1+0.0001x)^−½, σz = 0.20x
  - B: σy = 0.16x(1+0.0001x)^−½, σz = 0.12x
  - C: σy = 0.11x(1+0.0001x)^−½, σz = 0.08x(1+0.0002x)^−½
  - D: σy = 0.08x(1+0.0001x)^−½, σz = 0.06x(1+0.0015x)^−½
  - E: σy = 0.06x(1+0.0001x)^−½, σz = 0.03x(1+0.0003x)^−1
  - F: σy = 0.04x(1+0.0001x)^−½, σz = 0.016x(1+0.0003x)^−1
- หาค่าสูงสุดที่พื้น: วนคำนวณ C หลายระยะ x แล้วเลือกค่ามากสุด (แสดงกราฟถ้าผู้ใช้ต้องการ)

## 7. มาตรฐานคุณภาพอากาศในบรรยากาศทั่วไปของไทย (ตรวจฉบับล่าสุดที่ pcd.go.th)
- PM2.5: เฉลี่ย 24 ชม. ≤ 37.5 µg/m³, เฉลี่ยรายปี ≤ 15 µg/m³ (ใช้ตั้งแต่ 1 มิ.ย. 2566)
- PM10: เฉลี่ย 24 ชม. ≤ 120 µg/m³, เฉลี่ยรายปี ≤ 50 µg/m³
