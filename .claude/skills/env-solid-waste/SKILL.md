# ขยะมูลฝอย (Solid Waste)

ทำตาม "รูปแบบรายงานการคำนวณ" ใน `CLAUDE.md` และใช้ Python คำนวณตัวเลขจริง

## 1. ปริมาณขยะ
- `W (kg/d) = ประชากร × อัตราผลิตขยะ` (ไทยเฉลี่ย ~1.1–1.2 kg/คน/วัน, เมืองใหญ่สูงกว่า)
- ปริมาตร `V = W / ρ`
  - ขยะหลวม ~150–300 kg/m³, ในรถอัด ~300–500 kg/m³, บดอัดในหลุม ~600–900 kg/m³
- ความชื้น (ฐานเปียก): `MC (%) = (น้ำหนักเปียก − น้ำหนักแห้ง) / น้ำหนักเปียก × 100`

## 2. การเก็บขน
- จำนวนเที่ยว/วัน = `ปริมาตรขยะต่อวัน / (ความจุรถ × ประสิทธิภาพการบรรจุ)`
- เวลาต่อเที่ยว = เก็บขยะ + เดินทางไป-กลับ + ที่จุดทิ้ง
- จำนวนรถ = `จำนวนเที่ยว / เที่ยวที่รถ 1 คันทำได้ต่อวัน` (ปัดขึ้น + รถสำรอง)

## 3. หลุมฝังกลบ
- ปริมาตรขยะ = `W × 365 × จำนวนปี / ρ_บดอัด` (คิดประชากรเพิ่มรายปีถ้ามีข้อมูล)
- รวมดินกลบ: × (1 + 0.20–0.25)
- พื้นที่ = `ปริมาตร / ความลึกใช้งาน` แล้วเผื่อพื้นที่ส่วนสนับสนุน ~20–40%

## 4. น้ำชะขยะ (วิธี Swiss อย่างง่าย)
- `Q = (1/t) · P · A · K`
  - P = ฝนรายปี (mm), A = พื้นที่ (m²), t = จำนวนวินาที/วันในปี, K = 0.15–0.25 (บดอัดดี) ถึง 0.25–0.50 (บดอัดหลวม)
- แบบสมดุลน้ำ: น้ำชะ = ฝน − น้ำไหลบ่า − การระเหยคายน้ำ − ความชื้นที่ขยะ/ดินกักเก็บได้

## 5. ก๊าซจากหลุมฝังกลบ (LandGEM แบบง่าย)
- `Q_CH4 (ปีที่ t) = Σ k · L0 · Mi · e^(−k·ti)`
  - k ≈ 0.05 ปี⁻¹ (เขตร้อนชื้นอาจสูงกว่านี้), L0 ≈ 100 m³ CH4/ตัน, Mi = ขยะที่ฝังในปี i, ti = อายุขยะ
- ก๊าซรวม ≈ 2 × CH4 (มีมีเทนประมาณ 50%)

## 6. ปุ๋ยหมัก
- C/N ที่เหมาะสม 25–30:1, ความชื้น 50–60%
- ผสม 2 วัสดุ: `C/N = (m1·C1 + m2·C2) / (m1·N1 + m2·N2)` (C, N เป็น % ฐานแห้ง)
