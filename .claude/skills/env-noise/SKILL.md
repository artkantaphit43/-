# เสียง (Noise)

ทำตาม "รูปแบบรายงานการคำนวณ" ใน `CLAUDE.md` และใช้ Python คำนวณตัวเลขจริง (dB บวกตรงๆ ไม่ได้)

## 1. รวมและหักเสียง
- รวมหลายแหล่ง: `L = 10·log10(Σ 10^(Li/10))`
- หักเสียงพื้นหลัง: `Ls = 10·log10(10^(Lt/10) − 10^(Lb/10))` (ใช้ได้เมื่อ Lt > Lb)

## 2. ระยะทาง
- แหล่งกำเนิดจุด: `L2 = L1 − 20·log10(r2/r1)` (ลด 6 dB เมื่อระยะเพิ่มเป็น 2 เท่า)
- แหล่งกำเนิดเส้น (ถนน): `L2 = L1 − 10·log10(r2/r1)` (ลด 3 dB เมื่อระยะเพิ่มเป็น 2 เท่า)
- จากกำลังเสียง: `Lp = Lw − 20·log10(r) − 11` (กลางอากาศ), `− 8` (วางบนพื้น)

## 3. ระดับเสียงเฉลี่ย
- `Leq = 10·log10( (1/T) · Σ ti · 10^(Li/10) )`
- `Ldn = 10·log10( (1/24)·[15·10^(Ld/10) + 9·10^((Ln+10)/10)] )` (กลางคืน 22:00–07:00 บวก 10 dB)

## 4. เสียงในที่ทำงาน
- เวลาที่ยอมให้ได้รับ (exchange rate 3 dB): `T (h) = 8 / 2^((L − 85)/3)`
- ปริมาณเสียงสะสม: `D (%) = 100 · Σ (Ci / Ti)` (เกิน 100% = เกินมาตรฐาน)
- TWA จาก D: `TWA = 85 + 10·log10(D/100)`

## 5. กำแพงกันเสียง (Maekawa)
- Fresnel number: `N = 2δ/λ` (δ = ความต่างระยะทางเสียงที่อ้อมกำแพงกับระยะตรง, λ = c/f, c ≈ 343 m/s)
- การลดเสียงโดยประมาณ: `IL ≈ 10·log10(3 + 20N)` dB (โดยทั่วไปไม่เกิน ~20–25 dB)

## 6. มาตรฐานไทย (ตรวจฉบับล่าสุดก่อนใช้จริง)
- **เสียงในบรรยากาศทั่วไป (กก.วล.)**: Leq 24 ชม. ≤ 70 dBA, ระดับเสียงสูงสุด (Lmax) ≤ 115 dBA
- **เสียงรบกวน**: คำนวณระดับการรบกวนตามวิธีของกรมควบคุมมลพิษ ถ้าเกิน 10 dBA ถือว่าเป็นเสียงรบกวน
- **ในที่ทำงาน (กรมสวัสดิการและคุ้มครองแรงงาน 2561)**: 8 ชม. ≤ 85 dBA (exchange rate 3 dB), เสียงกระแทก ≤ 140 dB
