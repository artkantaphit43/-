# น้ำประปา (Water Supply)

ทำตาม "รูปแบบรายงานการคำนวณ" ใน `CLAUDE.md` และใช้ Python คำนวณตัวเลขจริง

## 1. ความต้องการน้ำ
- `Q เฉลี่ย = ประชากร × อัตราใช้น้ำ` (ไทยในเมือง ~150–250 L/คน/วัน, ชนบท ~50–100)
- วันใช้น้ำสูงสุด = 1.2–1.5 × เฉลี่ย, ชั่วโมงสูงสุด = 1.5–2.5 × เฉลี่ย
- ประชากรในอนาคต: `P_n = P_0 (1 + r)^n`

## 2. คลอรีน
- ปริมาณที่ต้องเติม = ความต้องการคลอรีน (demand) + คลอรีนคงเหลือ (residual)
- `คลอรีน (kg/d) = Q (m³/d) × C (mg/L) / 1000`
- ถ้าใช้สารประกอบ: หารด้วยสัดส่วนคลอรีนใช้ได้ (แคลเซียมไฮโปคลอไรต์ ~60–70%, โซเดียมไฮโปคลอไรต์ ~10–15%)
- CT: `CT = C (mg/L) × t10 (min)`
- คลอรีนอิสระคงเหลือปลายท่อ ~0.2–0.5 mg/L (ตรวจตามเกณฑ์กรมอนามัย/การประปาฉบับล่าสุด)

## 3. การตกตะกอนด้วยสารเคมี
- ปริมาณสารส้ม = ค่าจาก jar test (mg/L) × Q
- สารส้ม (Al2(SO4)3·14H2O) 1 mg/L ใช้ความเป็นด่าง ≈ 0.5 mg/L as CaCO3
- ความชันความเร็ว: `G = √(P / (μ·V))`
  - กวนเร็ว: G 600–1,000 s⁻¹, t 10–60 s
  - กวนช้า: G 20–80 s⁻¹, t 20–40 min, Gt 2×10⁴–2×10⁵

## 4. ถังตกตะกอน
- กฎของสโตกส์: `vs = g(ρp − ρw)d² / (18μ)` (μ น้ำ 25 °C ≈ 0.89×10⁻³ Pa·s)
- `SOR = Q / A`, ตะกอนสารส้ม ~1–2 m/h (24–48 m³/m²·d), t 2–4 h

## 5. ถังกรอง
- `อัตรากรอง = Q / A`
- กรองเร็ว: 5–15 m/h (120–360 m³/m²·d)
- กรองช้า: 0.1–0.4 m/h
- จำนวนถังกรองควร ≥ 2 เพื่อล้างย้อนได้โดยไม่หยุดผลิต
