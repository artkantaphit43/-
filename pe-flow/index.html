ตรวจ LG ก่อนยื่น

  • ผู้รับประโยชน์ = ชื่อผู้ว่าจ้างถูกต้องตามสัญญา
  • จำนวนเงิน ตัวเลข = ตัวอักษร = % ที่กำหนด
  • ชื่อโครงการ / เลขที่ประกาศ / เลขที่สัญญา ตรง
  • ระยะเวลาค้ำ ครอบคลุมถึงสิ้นสุดระยะรับประกัน (ถ้ากำหนด)
  • ใช้แบบฟอร์มตามที่ผู้ว่าจ้างกำหนด · ลายเซ็นผู้มีอำนาจธนาคาร

ตรวจสัญญาที่ได้กลับ (1.6)

  • ลายเซ็นผู้ว่าจ้าง + ชื่อตัวบรรจง + ตำแหน่ง ครบทุกจุด
  • ลายเซ็นฝ่ายเรา ตรงกับผู้มีอำนาจ + ตราบริษัท (ถ้ากำหนด)
  • พยาน ลงนามครบ 2 คน
  • เลขที่สัญญา + วันที่ลงนาม เขียนครบ ไม่เว้นว่าง
  • ลงชื่อย่อทุกหน้า · จุดแก้ไข/ขีดฆ่ามีลายเซ็นกำกับ
  • ภาคผนวกครบ: TOR, BOQ, แบบ, เงื่อนไข, แผนงวด
  • จำนวนหน้าเรียงครบ ไม่มีหน้าหาย/ซ้ำ
  • อากรแสตมป์ติดครบ/ขีดฆ่า หรือมีหลักฐาน e-Stamp

“สรุปสัญญา 1 หน้า” ต้องมี

  • เลขที่สัญญา · วันลงนาม · วันเริ่ม–วันสิ้นสุด · จำนวนวัน
  • วงเงิน · ตารางงวดงาน–งวดเงิน
  • ค่าปรับต่อวัน · เงื่อนไขขยายเวลา
  • หลักประกัน: เลขที่ LG / ธนาคาร / วันหมดอายุ
  • เงินล่วงหน้า · Retention · ระยะรับประกัน
  • ผู้ติดต่อ/ผู้ควบคุมงาน · ที่อยู่ส่งหนังสือตามสัญญา

ระวัง

  • ดูหนังสือรับรองบริษัท ข้อ “กรรมการผู้มีอำนาจ” ต้องลงนามกี่คน ต้องประทับตราหรือไม่

ตรวจเมื่อได้รับกลับ

หนังสือให้เริ่มงาน
  • ระบุวันเริ่มงานชัดเจน · ผู้ลงนามมีอำนาจ
  • เลขที่สัญญา/ชื่อโครงการตรง
บันทึกส่งมอบพื้นที่
  • ลงนามครบทั้ง 2 ฝ่าย + วันที่
  • แนบผังหมุด + ค่าระดับ + รูปสภาพเดิม
  • ระบุพื้นที่ที่ยังส่งมอบไม่ได้ (ถ้ามี)
แผนงานที่อนุมัติ
  • ตราอนุมัติ + ลายเซ็น + วันที่ → ใช้เป็น Baseline
กรมธรรม์ประกันภัย
  • ชื่อผู้เอาประกัน/ผู้รับประโยชน์ตามสัญญา
  • ทุนประกัน + ระยะคุ้มครองครอบคลุมทั้งโครงการ

จดลงปฏิทินทันที

  • วันเริ่ม – วันสิ้นสุดสัญญา
  • กำหนดส่งเอกสารตามสัญญา (แผนงาน ฯลฯ)
  • กำหนดแล้วเสร็จของแต่ละงวดงาน
  • วันหมดอายุ: LG · กรมธรรม์ · ใบ กว. ของทีม

ระวัง

  • ห้ามเข้าทำงานก่อนได้หนังสือให้เริ่มงานและรับมอบพื้นที่เป็นลายลักษณ์อักษร
  • ส่งมอบพื้นที่ช้า/ไม่ครบ → ทำหนังสือแจ้งทันที เพื่อรักษาสิทธิ์ขอขยายเวลา
  • วันเริ่มสัญญา = วันเริ่มนับเวลาและค่าปรับ

เคล็ดลับ

ถามใน Kick-off ให้ชัดว่า “ใครมีอำนาจสั่งงาน/อนุมัติ” และ “ส่งเอกสารช่องทางไหนถือว่าส่งแล้ว” แล้วให้อยู่ใน MOM

ก่อนกลับบ้าน (ทุกวัน)

  • Daily Report ส่ง CM แล้ว

  • เอกสารเข้าวันนี้ ลงรับ–สแกน–Register ครบ
  • พรุ่งนี้มีงานต้องขอตรวจ? ยื่นใบขอตรวจงานแล้ว
  • มีคำสั่งด้วยวาจา? ทำหนังสือยืนยันแล้ว

  • Register: รายการเลยกำหนด → ทวง

  • ความก้าวหน้า vs แผน (Look-ahead)
  • MOM ที่ยังไม่ได้ลงนาม
  • Backup ไฟล์ทั้งหมด
