1ทำสัญญา
เมื่อ: ได้หนังสือเชิญทำสัญญา → ก่อนวันนัดลงนาม
✓ สัญญาลงนามครบ 2 ฝ่าย
  • ตรวจร่างสัญญาเทียบ TOR / BOQ: วงเงิน ระยะเวลา งวดงาน ค่าปรับ ระยะรับประกัน
  • ขอ หลักประกันสัญญา (LG) ภาครัฐ 5% · หนังสือรับรองบริษัท · หนังสือมอบอำนาจ (อากร 10/30 บ.)
  • ยื่น + ลงนาม → ผู้ว่าจ้าง กรรมการผู้มีอำนาจ + ตรา (ถ้ากำหนด) + พยาน 2
  • บัญชีชำระอากรสัญญา 1 บ. / 1,000 บ. → สรรพากร
  • สัญญาคู่ฉบับ: ลายเซ็นครบ 2 ฝ่าย + พยาน · ชื่อย่อทุกหน้า
  • เลขที่/วันที่ลงนามไม่ว่าง · ภาคผนวกครบ · จุดแก้มีลายเซ็นกำกับ
  • LG: ผู้รับประโยชน์ · วงเงิน · วันหมดอายุ ถูกต้อง
  • หลักฐานชำระอากร / e-Stamp

2เตรียมเริ่มงาน
เมื่อ: หลังลงนาม → ก่อนเข้าพื้นที่ (ตามวันในสัญญา)
✓ ได้หนังสือให้เริ่มงาน + รับมอบพื้นที่
  • แผนงาน / S-Curve · ผังองค์กร + สำเนาใบ กว. · แผนความปลอดภัย · Submittal Schedule
  • กรมธรรม์ CAR (ถ้ากำหนด) · ขอเงินล่วงหน้า + LG เงินล่วงหน้า (ถ้ามี)
  • ยื่นพร้อมใบนำส่ง → ผู้ว่าจ้าง / CM · ขอไฟ–น้ำชั่วคราว ป้ายโครงการ
  • ตั้ง Register + Folder · ประชุม Kick-off
  • หนังสือให้เริ่มงาน: วันเริ่ม → คำนวณวันสิ้นสุดสัญญา · ผู้ลงนามมีอำนาจ
  • บันทึกส่งมอบพื้นที่: ลงนาม 2 ฝ่าย + ผังหมุด BM + รูปสภาพเดิม
  • แผนงานที่อนุมัติ = Baseline · MOM Kick-off ลงนามทุกฝ่าย

3ขออนุมัติ
ก่อนทำ
เมื่อ: ก่อนสั่งของ / ก่อนทำ 2–4 สัปดาห์ · ทุกรายการ
✓ ได้สถานะ A หรือ B
  • Shop Drawing · วัสดุ + ตัวอย่าง/มอก./ผลทดสอบ · Method Statement
  • ใส่เลขที่ + Rev. จาก Register · PM ตรวจและเซ็น
  • ยื่นพร้อมใบนำส่ง → CM ให้เซ็นรับ + วันที่ · ติดตามในประชุมทุกสัปดาห์
  • แบบไม่ชัด/ขัดกัน → RFI ถามเป็นหนังสือ
  • ตราสถานะ: A/B = ใช้ได้ · C/D = ห้ามใช้ แก้ Rev.+1 ส่งใหม่
  • ลายเซ็นผู้พิจารณา + วันที่ · เลขที่/Rev. ตรงที่ส่ง
  • อ่านคอมเมนต์ทุกหน้า · กระทบราคา/เวลา → แจ้งเป็นหนังสือ

4ควบคุมงาน
ก่อสร้าง
เมื่อ: ทุกวัน / สัปดาห์ / เดือน + ทุกครั้งที่เกิดเหตุ
✓ งานครบตามงวด + ผลทดสอบผ่าน
  • ทุกวัน: Daily Report + รูป (งานที่จะถูกปิด) → CM
  • ทุกสัปดาห์: ประชุม + MOM · ทุกเดือน: Monthly Report + S-Curve
  • ก่อนเท/ก่อนปิดงาน: ใบขอตรวจงาน ล่วงหน้า (เช่น ≥ 24 ชม.) · ส่งตัวอย่างทดสอบ
  • งานเพิ่ม–ลด / ล่าช้า: แจ้ง VO / EOT เป็นหนังสือทันที ภาครัฐ ขอขยายเวลา ภายใน 15 วันนับถัดจากเหตุสิ้นสุด
  • Daily / ใบขอตรวจงาน: CM เซ็นรับ · ผล “ผ่าน” + วัน/เวลา
  • MOM ลงนามทุกฝ่าย · ข้อความตรงที่ตกลง
  • ผลแล็บ: ลายเซ็นผู้ทดสอบ + ตราแล็บ · ค่า ≥ Spec
  • VO อนุมัติเป็นหนังสือก่อนลงมือ · คำสั่งด้วยวาจา → ทำหนังสือยืนยันใน 1–2 วัน

5ส่งงวด
& เบิกเงิน
เมื่อ: เนื้องานครบตามงวดในสัญญา · ทำซ้ำทุกงวด
✓ ได้ใบตรวจรับ + ได้เงิน
↺ งวดถัดไป กลับขั้น 3
  • ตรวจงานภายใน + แก้ Defect ก่อนเรียกตรวจ
  • หนังสือส่งมอบงานงวด (กรรมการ + ตรา) + สรุปผลงาน รูป ผลทดสอบ → ผู้ว่าจ้าง / กก.ตรวจรับ
  • หลังตรวจรับ: บัญชีวางบิล ใบแจ้งหนี้ (+ ใบกำกับภาษีตามแนวทางบัญชี)
  • เลขรับ + วันที่ ของหนังสือส่งงาน = หลักฐานวันส่งงาน (ค่าปรับ)
  • ใบตรวจรับงวด: ลงนามครบทุกคน · ระบุงวด + วันที่
  • 50 ทวิ: เลขภาษีเราถูก · ยอดตรง (หัก ภาครัฐ 1% / เอกชน 3%)
09_Payment/งวดN · ต้นฉบับ 50 ทวิ → บัญชี
6ส่งมอบงาน
& ปิดโครงการ
เมื่อ: งานเสร็จ ~90–95% → ส่งงวดสุดท้าย
✓ ได้หนังสือรับมอบงาน
  • ทดสอบระบบ (T&C) · Punch List · ตรวจร่วมก่อนส่งมอบ
  • เอกสารส่งมอบ: As-built (วิศวกร + เลข กว.) · คู่มือ O&M · ใบรับประกัน · กุญแจ/อะไหล่ · บันทึกอบรม
  • หนังสือส่งมอบงานงวดสุดท้าย + ใบนำส่งแจงทุกรายการ → ผู้ว่าจ้าง
  • หนังสือรับมอบงาน: วันที่รับมอบ = วันเริ่มนับรับประกัน
  • ผู้รับเซ็นรับเอกสารส่งมอบครบทุกรายการ
  • ขอหนังสือรับรองผลงาน · ขอคืน LG เงินล่วงหน้า · ออกจากพื้นที่
07 · 12ปิดแฟ้ม: Register ไม่มีค้าง
7ระยะรับประกัน
เมื่อ: ตามสัญญา เช่น 1–2 ปี นับจากวันรับมอบ
✓ ได้หลักประกันคืน → ปิดโครงการ
  • รับแจ้งซ่อม → ลง Defect Log → ซ่อมในเวลาที่สัญญากำหนด
  • ก่อนครบ 30–60 วัน: ตรวจร่วมครั้งสุดท้าย
  • หนังสือขอคืนหลักประกันสัญญา / Retention → ผู้ว่าจ้าง · LG ที่ได้คืน → ธนาคาร ยกเลิก
  • บันทึกการซ่อม: ผู้ว่าจ้างเซ็นรับ + รูปก่อน–หลัง
  • ได้ต้นฉบับ LG คืนจริง · เลขที่/จำนวนเงินตรง · Retention ครบ
  • หนังสือยืนยันยกเลิก LG จากธนาคาร

วงจรเอกสาร — ใช้กับทุกฉบับ

  1. ขอเลขที่จาก Register · ตรวจทานเอง
  2. ผู้มีอำนาจลงนาม / ประทับตรา
  3. สแกนฉบับที่ส่ง → ยื่นพร้อมใบนำส่ง
  4. ให้ผู้รับเซ็นรับ + วันที่ + เวลา (หรือตรารับ + เลขรับ)
  5. ลง Register + กำหนดตอบ → ติดตาม
  6. รับกลับ → ตรวจ (กล่องกลาง) → สแกน → ตั้งชื่อ → Folder → Register

ตรวจทุกเอกสารที่ได้กลับ

  • ลายเซ็นหมึกจริง ครบทุกช่อง
  • ชื่อตัวบรรจง + ตำแหน่ง = ผู้มีอำนาจ
  • ตราประทับชัด (ถ้ากำหนด) · ตราสถานะ
  • เลขที่ / วันที่ / Rev. ตรงกับที่ส่ง
  • ครบทุกหน้า + สิ่งที่ส่งมาด้วย
  • จุดแก้ไข/ขีดฆ่า มีลายเซ็นกำกับ
  • ไม่ครบ → แจ้งขอแก้เป็นหนังสือ ห้ามแก้เอง/เซ็นแทน

กฎเหล็ก PE

  • ไม่มีหนังสือ = ไม่เกิดขึ้น คำสั่งด้วยวาจาต้องยืนยันเป็นหนังสือ
  • ห้ามทำงานเพิ่ม/เปลี่ยนวัสดุ ก่อนได้อนุมัติ
  • ห้ามใช้แบบ/วัสดุที่ไม่ได้ A หรือ B
  • ถ่ายรูปงานก่อนถูกปิดเสมอ
  • ได้เอกสารมา → ลงรับ ตรวจ สแกน ให้จบในวันเดียว
  • เฝ้าวันหมดอายุ: LG · ประกันภัย · ใบ กว.
